# Proposal

## Why

**实测确认：`deepseek-v4.1-flash-1017` 能看图。** 发一张图（左朱红方块 / 右墨色圆）问形状与颜色，
它准确答出 ✓。所以"视频只能转文字"是**旧认知**，不是约束 ✗。

现状：视频导入只做**转写** ✗ —— 画面从来没进过任何环节 ✓：
- 有画面没说话的素材（风景、演示）→ 转写是空的 → 对生成零帮助 ✗
- 画面里有关键信息（PPT/板书/字幕）→ 看不见 ✗
- 粗剪按时间顺序切 ✗ → 是**盲剪** ✓

## What Changes

- **抽关键帧**（ffmpeg 场景变化检测，5~10 张，本地 ✓ 不联网 ✓）
- **送进模型描述**（视觉 ✓）：每帧一句话——画了什么、适合什么位置
- **产出结构化结果**：`[{时间点, 文件, 描述, 可用途}]`
- 关键帧本身留作**资产**（可被封面/分镜引用 ✓）

## Capabilities

### New Capabilities
- `video-frame-understanding`: 视频 → 关键帧 → 视觉描述（为剪辑选镜头与画面配文提供依据）

## Impact
- **Python**：新增抽帧 + 视觉调用；`ffmpeg` 已是既有依赖 ✓
- **成本**：每帧几百 token（5~10 帧 / 条视频）
- **明确不做（本期）**：不做"按画面自动重排剪辑"✗ —— 先证明"能看懂"，再谈怎么用 ✓
