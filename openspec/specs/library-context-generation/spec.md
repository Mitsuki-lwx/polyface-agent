# library-context-generation Specification

## Purpose
让"查到"直接接上"用上"：生成时可选择性引用本地历史素材，但**不能让历史素材污染事实**。

## Requirements

### Requirement: 引用是可选的，默认关闭

生成时 MUST 提供一个显式开关；**未勾选时 MUST NOT** 检索、MUST NOT 把任何历史素材发给模型。
开关状态 MUST 随成稿一起留下记录（便于事后解释产出差异）。

#### Scenario: 未勾选
- **WHEN** 用户不勾「关联素材库」
- **THEN** 发给模型的请求与改动前**完全一致**（逐字节可对照的理解：无新增字段、无新增调用）

### Requirement: 只引用检索到的少数几条

勾选时 MUST 只引用**按相关性检索出的 3 条**（上限可配），MUST NOT 把整个库传过去。

#### Scenario: 库里有 50 条
- **WHEN** 勾选生成
- **THEN** 只带 3 条进 prompt，且这 3 条与当前素材有关键词/全文相关性

### Requirement: 参考不得成为事实

被引用素材 MUST 只用于借鉴角度与表达；成稿中的**事实** MUST 仍然只来自本次素材。
质检 MUST 能对"来自参考素材的事实"报错（复用既有事实核对）。

#### Scenario: 参考素材里有个数字
- **WHEN** 参考素材写着"2小时完成"，而本次素材没提这个数字，成稿里却出现了
- **THEN** 质检报出"新增断言/数字不在本次素材"

### Requirement: 可追溯

成稿 MUST 记录"参考了哪几条"（素材 id + 标题），并 MUST 在界面可见。

#### Scenario: 事后解释产出差异
- **WHEN** 同一素材勾/不勾各生成一次
- **THEN** 两次产出都能看到是否引用过库、引用了哪些

### Requirement: 跨时间也不得逐字重复

被引用素材的句子 MUST 进入去重清单（`avoid`），与同批跨平台去重同一套检查。

#### Scenario: 历史素材里有金句
- **WHEN** 成稿逐字复用了参考素材的句子
- **THEN** 既有的重合检查报出来（而不是因为"是以前的素材"就豁免 ✗）
