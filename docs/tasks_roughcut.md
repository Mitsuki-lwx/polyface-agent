## T1 · 造一份可复现的测试素材

- **做什么**：用本机 TTS 合成一段中文口播（含**故意插入的长停顿**），配上竖屏画面做成 mp4
- **影响文件**：实验目录 `.workbuddy-ai/roughcut-lab/` → 定稿后收进 `scripts/` 作为 fixture 生成器
- **依赖**：无
- **参考资料**：
  - 已跑通的做法：`tts3.ps1` + `script.txt`（**中文必须写成 UTF-8 的 txt 再由脚本显式读**）
  - ⚠️ 坑：PowerShell 5.1 按系统代码页（GBK）读 `.ps1` → 脚本里的中文会变乱码并被念出来
  - 本机可用语音：`Microsoft Huihui Desktop`（zh-CN）
- **完成判据**：一条命令重新生成同一素材；`ffprobe` 时长与预期一致

## T2 · 前置探测与大声失败

- **做什么**：检查输入文件存在、能被 ffprobe 识别、**有音轨**；缺 ffmpeg / 缺 ASR 时明确报错并给一句怎么修
- **影响文件**：新模块（建议 `python-service/app/pipeline/roughcut.py`）；复用 `python-service/app/pipeline/media.py`
- **依赖**：无
- **参考资料**：`media.py:38-56`（`_ffmpeg_bin` / `has_ffmpeg`）、`media.py:79-87`（ffprobe 解析）
- **完成判据**：三种输入（不存在的文件 / 无音轨的视频 / 摘掉 ffmpeg）给出**互不相同**的明确错误

## T3 · 找停顿

- **做什么**：跑 `silencedetect`，把输出解析成"剪掉哪几段"的列表
- **影响文件**：同上模块
- **依赖**：T2
- **参考资料**：
  - 命令形态：`ffmpeg -i IN -af silencedetect=noise=<门限>dB:d=<阈值> -f null -`
  - 输出在 stderr：`silence_start:` / `silence_end:` / `silence_duration:`，需正则解析
  - **实测**：噪声门限 -20~-40dB 几乎不影响结果；**真正敏感的是时长阈值**（0.3s→8 段 / 0.8s→4 段 / 1.0s→3 段）
- **完成判据**：同输入同参数 → 剪点列表稳定可复现；阈值调大 → 剪点**单调减少**

## T4 · 参数外露与配置来源（**这一条决定"能不能商量"**）

- **做什么**：把**所有可调值**抽成参数，并实现固定的来源优先级
  `内置默认 < 配置文件 < 命令行参数`
- **影响文件**：同上模块 + 一个配置文件（建议 `roughcut.json` 放项目根或数据目录）
- **依赖**：T3（先知道有哪些参数）
- **参考资料**：
  - 参数至少覆盖：停顿阈值、噪声门限、剪点两端余量、字幕字体/字号/颜色/描边/位置、ASR 模型、是否烧字幕
  - 项目既有的"配置优先级"写法可参考 `python-service/app/config.py`（配置项）与
    `python-service/app/pipeline/media.py:38-49`（配置 > 环境变量 > PATH 的三级回退）
- **完成判据**：
  - 改配置文件 → 不传任何命令行参数也生效
  - 命令行传参 → 覆盖配置文件
  - **没有任何一个可调值在代码里写死到改不了**

## T5 · 剪点预览与确认（**两段式**）

- **做什么**：默认行为是"先给看，再动手"——打印剪点清单 + 剪前/剪后时长 + **本次生效的全部参数**，
  然后等用户确认：回车执行 / 输入新阈值重算 / 放弃
- **影响文件**：同上模块
- **依赖**：T4
- **参考资料**：
  - 交互读入用标准库即可；**非交互模式（一键直跑）必须留**，供端到端脚本使用
  - ⚠️ 参考经验：项目里 `scripts/stop.sh` 的交互确认曾因"没有非交互开关"被记为可用性缺口（`docs/62` §4）
- **完成判据**：
  - 默认跑 → **不产生任何输出文件**，只打印预览
  - 回车 → 继续执行
  - 输入新阈值 → 用新值**重算**并再次预览（不退出）
  - 放弃 → 退出码 0，无副作用
  - 带非交互开关 → 不问，直接执行

## T6 · 剪掉停顿

- **做什么**：按剪点生成 ffmpeg 的 `select`/`aselect` 表达式并重编码，产出剪后视频
- **影响文件**：同上模块
- **依赖**：T5
- **参考资料**：
  - 实测形态（视频与音频**必须用同一个条件表达式**，否则音画不同步）：
    `-vf "select='not(<条件>)',setpts=N/FRAME_RATE/TB" -af "aselect='not(<条件>)',asetpts=N/SR/TB"`
  - 条件由若干 `between(t,起,止)` 用 `+` 连接
- **完成判据**：剪后时长 = 原时长 − 剪掉秒数（帧级误差）；播放时音画同步

## T7 · 转写（补"要时间戳"的入口）

- **做什么**：对**剪后**的视频做本地转写，拿到带起止时间的片段
- **影响文件**：`python-service/app/pipeline/asr.py`（新增入口，**不动**现有 `transcribe()`）
- **依赖**：T6
- **参考资料**：
  - 现有 `asr.py:44-46`（模型加载，进程内缓存）、`asr.py:50-57`（`transcribe()` 把时间戳丢掉了）
  - `faster_whisper` 的 `segments` 每项带 `.start` / `.end` / `.text`
  - ⚠️ **实测坑**：`faster-whisper 1.2.1` 与 `av 19` 不兼容（`av.open()` 已不接受 `metadata_errors`），
    传文件路径会在解码阶段抛 `TypeError`。**绕开：自己用 ffmpeg 解成 16k 单声道，用标准库读成
    float32 数组传进去**（传数组不走 PyAV 解码路径）
- **完成判据**：转写文本与台词一致（人名同音错可接受）；片段带正确起止时间

## T8 · 生成字幕文件

- **做什么**：把带时间戳的片段写成标准字幕文件
- **影响文件**：同上模块
- **依赖**：T7
- **参考资料**：项目已有字幕**解析**能力（`media.py` 的 `srt_to_text`），本任务是它的反向
- **完成判据**：产物能被 ffmpeg `subtitles` 滤镜直接读取；时间戳格式合法

## T9 · 烧字幕（样式可调 + 可预览）

- **做什么**：把字幕渲染进画面；**样式全部走 T4 的参数**；另提供一个"只渲染一帧"的预览能力
- **影响文件**：同上模块
- **依赖**：T8、T4
- **参考资料**：
  - 实测形态：`-vf "subtitles=<srt>:force_style='...'"`（本机 ffmpeg 带 libass）
  - 中文字体必须显式指定，否则可能渲染成方块（本机可用 `Microsoft YaHei`）
- **完成判据**：
  - 抽一帧能看到**正确的中文字幕**（不是方块、不是乱码、位置不压边）
  - **改字号/颜色/位置后，抽帧结果确实不同**
  - 预览模式只产出一张图，**不渲染整片**

## T10 · "剪了什么"摘要

- **做什么**：打印剪点摘要（段数 / 每段起止 / 剪掉总秒数 / 剪后时长 / 本次生效参数），并落一份机器可读的剪点文件
- **影响文件**：同上模块
- **依赖**：T6
- **参考资料**：无
- **完成判据**：摘要里的数字与 `ffprobe` 实测的剪后时长**对得上**

## T11 · 接入主流程（**必须有**）

- **做什么**：一个命令行入口把 T2→T10 串成一条命令；参数全部可见（`--help` 能看到有哪些旋钮）
- **影响文件**：`scripts/roughcut.py`（新）
- **依赖**：T2–T10
- **参考资料**：项目既有脚本风格 `scripts/probe_llm.py`、`scripts/e2e_fr51.py`
- **完成判据**：`--help` 列出全部可调参数及其默认值；一条命令从原始视频跑到成片

## T12 · 端到端验证（**必须有**）

- **做什么**：用 T1 的素材跑完整链路，逐条对 `checklist_roughcut.md`
- **影响文件**：`scripts/e2e_roughcut.py`（新）
- **依赖**：T11
- **参考资料**：既有 e2e 风格 `scripts/e2e_assets.py`、`scripts/e2e_fr51.py`
- **完成判据**：
  - 剪后时长确实变短，且与摘要自洽
  - 抽帧能看到中文字幕
  - 独立字幕文件存在且非空
  - **改一个参数 → 输出确实不同**（证明参数不是摆设）
  - **变异测试至少 1 次**：故意把剪点表达式改坏 → 确认 e2e 变红 → 还原
