## 2. 交付内容

### 2.1 Python 媒体层（新增）

| 模块 | 职责 |
|---|---|
| `pipeline/media.py` | ffmpeg/ffprobe 定位（配置 > `POLYFACE_FFMPEG` > PATH）、`probe()`（时长/音轨/字幕轨/推荐模式）、`srt_to_text()` 清洗、`extract_subtitle()`、`extract_audio_wav()`（16k 单声道）、超时保护 |

### 2.2 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/ingest/upload` | multipart → `data/media/{uuid}{ext}`；扩展名白名单；500MB 上限 |
| POST | `/api/ingest/probe` | 接受 `media_id` 或 `path`；路径校验（存在/非目录/白名单） |
| POST | `/api/ingest/transcribe` | 透传 Python 结果（status/text/source/chars/hint） |

| POST | `/probe`、`/transcribe`（Python） | 内部端点，**不感知 media_id**（维持既有边界） |

## 4. 关键实现说明

- **ASR 是可选增强，不是硬依赖**：这是本任务最重要的判断。若把 faster-whisper/torch 做成必装，模型 + torch（数百 MB~数 GB）会把"本地一键启动"这个核心卖点拖垮。现在：检测到就自动启用，没有就给一行可执行的安装命令。
- **字幕提取优先**：口播类视频常带字幕轨，`ffmpeg -map 0:s:0` 是零算力、秒级路径。实测中 SRT 的**相邻重复行被正确去重**（卡拉OK式字幕常见）。
- **失败绝不 5xx**：六种场景（有字幕/字幕空/无 ASR/ffmpeg 缺失/文件不可读/无音轨）全部降级为 `needs_manual` + 可执行指引，工具始终可用——用户至少能"粘贴文案"走原链路。
- **UC-12「无外部上传」落地**：全流程仅本地 ffmpeg + 可选本地 ASR；**明确排除一切云 ASR**（即使云服务效果更好）。
- **边界收敛**：media_id 拒绝 `../`、路径模式拒绝目录与非白名单扩展名；Python 侧不感知 media_id（路径由 Java 解析后传入），维持"Python 无状态、不碰数据库"的既有架构。
- **E2E 自造样本**：用 ffmpeg 现场生成带 mov_text 字幕轨的 mp4，测试不依赖任何外部素材，可重复运行。
