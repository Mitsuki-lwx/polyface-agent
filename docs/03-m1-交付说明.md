## 关键工程决策（踩坑记录）

1. **Java 调 Python 必须显式 HTTP/1.1**：JDK HttpClient 默认会尝试 HTTP/2 明文升级(h2c)，而 uvicorn/h11 不支持 → 连接被重置（`header parser received no bytes`）。已通过 `JdkClientHttpRequestFactory` + `HttpClient.Version.HTTP_1_1` 修复。
2. **启动脚本显式传 `--server.port=8080`**：防止环境变量 `SERVER__PORT` 意外覆盖端口（Spring 宽松绑定），保证一键启动可预期。
3. **LLM Key 零入库**：`.env` 只在 python-service 本地；仓库仅提交 `.env.example`。
