## 新增能力

- **平台 DNA**：douyin/gongzhonghao/zhihu/bilibili 各含 content_forms/style/structure_template/title_rules/tags/limits/viral_logic/hooks + `video_native` 标记
- **剪辑单 FR-50**：`ClipSheet{intro_note, scenes[], bgm_hint}`，scenes 含 seq/duration_hint/script/visual/subtitle/sound
- **用户模板**：`GenerateRequest.template`（UserTemplate：voice/opening/structure/closing/tag_style/taboo），mock 模式下 opening/closing 直接进正文；真实模式注入 prompt
- **Web 工作台**（`java-backend/src/main/resources/static/index.html`，零构建）：素材输入/解析/事实清单 → 5 平台勾选 → 模板折叠配置 → 一键生成 → 逐平台 Tab 审阅（标题/正文/标签/封面/改写说明/剪辑单/QA 警告）+ 复制全文 + 素材历史

## 架构增量

```
POST /api/platforms           （新增，Java→Python 透传）
POST /api/materials/{id}/generate  body 新增可选 template
Python: understand→brief→draft→[clip_sheet if video_native]→qa
Java:   static/index.html 托管于 :8080/
```

## 关键实现说明

- 前端采用**无构建静态 SPA**（非 React）：本地工具优先零依赖/零构建；如后续需要复杂交互，可迁移 React/Vue（见 ADR-015 提议）。
- 剪辑单与模板在 mock 与真实模式都有实现，便于无 Key 演示。
