### 关键证据：浏览器端到端（8/8）

```
===== 封面成图端到端实测 (BASE=http://127.0.0.1:18080) =====
  PASS A1 首页加载
  PASS A2 素材解析 + 事实确认
  PASS A3 生成稿件并出现「生成封面」按钮
  PASS B1 封面图真的加载出来（naturalWidth>0）  | 1080x1440
  PASS B2 尺寸是平台画布（3:4 竖版）  | 1080x1440
  PASS B3 url 指向 /api/media/  | /api/media/covers/draft-1-xhs-0b2586/cover.png
  PASS B4 端到端耗时在预算内（<60s）  | 0.9s
  PASS B5 /api/media 回的是 image/png 且是真 PNG 字节  | image/png 124103B
→ 8/8
```

**三件事因此被证明**：

1. **链路是通的**：浏览器 → Java `/api/drafts/{id}/cover` → Python `/compose/cover`
   → 后台 gimpish 渲染 → `GET /api/media/**` → `<img>` 真的解码出来（`naturalWidth>0`，
   不是"标签存在但图是死链"）。**端到端 0.9s**。
2. **降级是真降级**：gimpish 缺失/渲染失败/超时一律 200 + `needs_manual` + 安装指引，
   前端显示为**中性提示**而不是红色报错（`docs/64` §3 的不变量）。
3. **封面中文排版可用**：CJK 逐字折行 + 禁则标点处理 + 字号自适应，中文字体正常渲染。

## 3. 设计要点（为什么这么做）

| 决定 | 理由 |
|---|---|
| **自己产出 `scene.json`，只调一次 `gimpish export`** | gimpish 的契约是版本化 zod schema，直接写 JSON 比逐条跑 CLI 动词少 4 次 node 冷启动；且场景**可单测**（不需要 node 也能断言结构） |
| **每行文本独立成层** | `\n` 的多行语义依赖渲染器实现；我们要版式**逐像素确定、可单测** |
| **产物目录内保留 `scene.json`** | 用户可以 `gimpish -C <目录> serve` 打开继续手改 —— 这是选"声明式场景"而不是"直接拼像素"的回报 |
| **不 fork、不内嵌源码** | OpenCut 处于重写期、gimpish 处于 0.1.x；内嵌源码等于把它们的重构成本转嫁给自己（ADR-019 决策 3） |
| **`MediaDir` 抽成单一 Bean** | 入料与封面若各自解析 `media.dir`/`data-dir`，配置不一致就会出现"封面写得进、`/api/media` 读不出"的割裂 |

## 6. 观察（**不是缺陷**，如实记录）

| 观察 | 判定 | 说明 |
|---|---|---|
| 封面版式是"审美判断"，无法自动验收 | ⚠️ 已知边界 | 我们只承诺**确定性 + 中文排版基本规则**，不承诺"好看"。版式靠主题/模板演进 |
| 字宽是**估算**（CJK=1em、ASCII=0.53em…），非真实字体度量 | ⚠️ 已知近似 | 极端字符串可能仍有轻微溢出；这是不引入字体度量库的代价 |
| 渲染耗时 640~1280ms 波动 | ✅ 正常 | 主要是 node 冷启动；同进程连续渲染更稳定 |
| `setup.sh --quiet` 通过时无输出 | ⚠️ 旧跟进项 | `docs/62` §4 已记录，本次未动 |

## 8. 复现方式

```bash
# 1) Python（需 gimpish：npm i -g gimpish；或指到本机任意入口 js）
cd python-service
LLM_MOCK=true POLYFACE_GIMPISH=<gimpish 入口> \
  POLYFACE_DATA_DIR=<scratch> .venv/Scripts/python.exe -m uvicorn app.main:app --port 18000

# 2) Java（用新 jar —— 改了 index.html，必须重新 package，否则读的是旧副本）
bash scripts/mvn.sh -B -f java-backend/pom.xml package -DskipTests
POLYFACE_DATA_DIR=<scratch> POLYFACE_LLM_BASE_URL=http://127.0.0.1:18000 \
  java -jar java-backend/target/polyface.jar --server.port=18080

# 3) 端到端
BASE=http://127.0.0.1:18080 python-service/.venv/Scripts/python.exe scripts/e2e_cover.py
```
