# checklist —— 按场景切段

spec：`docs/spec_scene_split.md`　　tasks：`docs/tasks_scene_split.md`

---

## 1. 检测（T1）

- [ ] 三段纯色的合成视频 → 检出 ≥2 个切点，位置与真实边界差 < 0.5s
- [ ] 静态单场景视频 → 检出 0 个切点（不硬凑）
- [ ] PySceneDetect 没装 → **明确报错 + 安装指引**，不是返回空列表
- [ ] 阈值可改：调高 → 切点变少；调低 → 变多
- [ ] 同一输入 + 同一参数 → 两次结果完全相同（确定性）

## 2. 语音吸附（T2）

- [ ] 画面切点落在句子中间 → 吸附后与**语音边界**重合
- [ ] 吸附偏移超过上限 → **不吸**（宁可留原样，也不挪到另一句话里）
- [ ] 没有音轨 / 缺 ASR → 原样返回画面切点 + 标记 `speech_aligned=false`（**不静默**）
- [ ] 吸附只做**就近平移**：不会把边界挪到相反方向、不会产生重叠

## 3. 合并（T3）

- [ ] 低于最短时长的段 → **并入前一段**（不是丢掉）
- [ ] 第一段过短 → 并入**后一段**
- [ ] 合并后：升序、无重叠、**总长等于源时长**（守恒）
- [ ] 改最短时长 → 段数确实变化

## 4. 方案与勾选（T4/T6）

- [ ] `--dry-run` → **不产出任何视频文件**
- [ ] 方案里每段有：起止、时长、缩略图
- [ ] N 段 → N 张缩略图，且都非空
- [ ] `--pick 2` → 只切第 2 段
- [ ] 检测结果落盘；改阈值重跑时**不重新解码整条视频**（可观测：第二次更快）
- [ ] 落盘里含检测器版本与参数（可复核"当时用的是什么"）

## 5. 切段（T5）

- [ ] 切出的段数 = 勾选数
- [ ] 每段时长与方案一致（±0.2s）
- [ ] **源文件不动**（mtime 不变）
- [ ] 段的时间戳来自程序（不取检测器的自由文本）

## 6. 接入主流程（T7）

- [ ] 新任务种类可发起，进度可看、能取消
- [ ] 切出的每段**登记成素材**（出现在素材库）
- [ ] 每段血缘挂回源视频（能反查"这条是从哪个视频的哪一段来的"）
- [ ] 界面：能看方案（缩略图 + 时长）、能勾选、能切
- [ ] 缺 PySceneDetect 时，界面能看到"怎么装"（不是空白）

## 7. 端到端（T8，**必须真素材**）

- [ ] 真实多场景素材 → 出方案 → 勾选 → 切 → 拿一段跑粗剪
- [ ] 切点位置**逐条核对**（对着源视频看）
- [ ] 没有把一句话切断（听切点前后 1 秒）
- [ ] **切错的逐条列出**（报忧不报喜）
- [ ] 原始输出（方案、时长、缩略图）贴进本文件

## 8. 文档（T9）

- [ ] 新 ADR 记录"引入 PySceneDetect"与代价（发布包带上它）
- [ ] SRS 的 FR-53 缺口表去掉"分镜"
- [ ] README 补新依赖安装说明
- [ ] `grep` 确认 SRS/README 与实现一致

## 9. 变异测试

- [ ] 把"短段并入前一段"改成"丢掉" → §3 的守恒断言**变红** → 还原
- [ ] 去掉吸附的偏移上限 → §2 的"不挪到另一句话"**变红** → 还原
- [ ] 让缺依赖时返回空列表（而不是报错）→ §1 的"明确报错"**变红** → 还原
- [ ] 让 `--dry-run` 也真的切 → §4 的"不产出任何视频"**变红** → 还原
