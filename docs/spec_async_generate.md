# spec —— 生成任务异步化：复用任务底座（M8 第二片）

版本：2026-10-07　　对应 tasks：`docs/tasks_async_generate.md`　　验收：`docs/checklist_async_generate.md`

---

## 1. 背景

「生成稿件」是**最常用**的功能，但它跟粗剪当初是**同一个病**：

- 前端同步 fetch，Java 侧 240s 预算，**多平台串行必然超时**；
- 真实单平台实测 **60~250s**（上游限流时更久），3 个平台就远超预算；
- 超时后前端只有一句"失败"，**看不到跑到哪了**；
- 而 Python 侧**内部其实是逐平台的**（understand → 每平台 brief/draft/qa），
  这份进度信息**存在但没传出来**。

刚做完的任务底座（`docs/spec_roughcut_jobs.md`）正是为这个准备的 —— 本片是**复用**，不是新建。

## 2. 目标用户

作者本人（与前面几片一致）。单机单用户，串行。

## 3. 能力清单（一句话一条）

1. 生成改成**后台任务**：发起后立刻返回，前端不阻塞
2. **平台级进度**：能看到"正在跑第 2/3 个平台"
3. **阶段级进度**：单个平台内部能看到走到哪一步（理解 / 策略 / 成稿 / 质检 / 改写）
4. 一个任务 = **一次生成请求**（可含多个平台），任务详情列出每个平台的状态与结果
5. 某个平台失败**不丢其他平台的成果**（沿用 FR-70 的既有语义）
6. **失败平台可一键重试**（只重跑失败的，不重跑已成功的）
7. 产物（草稿）照旧进既有的稿件体系，前端能直接跳到稿件
8. 全程**可见**：失败时能看出是哪个平台、哪一步、为什么

## 4. 非功能要求

- **复用既有底座**：job 表 / 进度读取 / 任务面板 —— 不另造一套
- **理解阶段只跑一次**：不能因为拆成按平台调用就把最贵的那次调用重复 N 遍
- **观测不得影响业务**（沿用既有硬不变量）
- **不引入新依赖**
- **单次调用仍受既有超时预算约束**：拆成按平台后，每次调用都落在预算内
- **CLI 与既有 API 不受影响**：本片只新增路径，不改既有 `/generate` 的语义

## 5. 设计骨架

**关键决定：把"一次大调用"拆成"理解一次 + 每平台一次"，由 Java 编排。**

```
Java 任务线程：
  ① 理解（一次）—— 已有已确认事实就直接用，否则调 /analyze
  ② 对每个平台：调 /generate（只带这一个平台 + 已确认事实）
       ↑ 每次调用都落在既有的单次预算内；平台级进度天然可得
  ③ 汇总：成功的进稿件体系，失败的记原因 → 可一键重试
```

**为什么这么拆**（三个好处同时拿到）：

| 好处 | 怎么来的 |
|---|---|
| 平台级进度 | Java 的循环本身就知道"第几个平台" |
| 每次调用不超预算 | 单平台 60~250s，落在既有 240s 预算内；多平台不再累加成一个超长调用 |
| 重试失败平台 | 失败的就是"某个平台那一次调用"，重跑它即可，不必重跑全部 |

**阶段级进度**靠**阶段事件文件**（Python 侧已有底座）：

```
Java 建任务时给一个事件文件路径 ──► 传给 Python 的 /generate
   Java 写自己的事件（平台边界）  ┐
   Python 写阶段事件（理解/策略/成稿/质检）├─► 同一个 JSONL ──► Java 读它算进度
```

> ⚠️ **两个进程追加同一个文件**：这是刻意的取舍 —— 收益是"进度只有一个来源、前端只读一个文件"，
> 代价是需要容忍交错。因为①两边都是**一行一条、写完即关**的追加，
> ②读取端**本来就会跳过坏行**（`docs/spec_roughcut_jobs.md` 已实现），
> 所以最坏情况是丢一行进度，不会崩。

**与前一片的关系**：`RoughcutRunner` 起子进程、本片起**HTTP 调用**，
但"起任务 / 读事件算进度 / 落终态 / 产物入素材库"这套骨架**共用**。

## 6. Out of Scope（本版不做）

- **断点续跑**（进程被杀后从中间继续）—— 与"重试失败平台"部分重叠，且代价高
- 多任务并发调度（仍串行）
- 把 `/analyze`、`/learn`、`/compose/cover` 也异步化（按需再做）
- 生成结果的**版本管理 / 对比**
- 任务优先级、定时任务
- 工作台内的成稿**预览**（照旧跳稿件页）
