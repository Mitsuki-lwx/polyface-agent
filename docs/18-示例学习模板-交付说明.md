## 2. 交付内容

### 2.1 数据层（Store）

- `template` 表新增 `status`（`draft` / `active`，默认 `active`）与 `source_note`
- **幂等迁移**：`PRAGMA table_info(template)` 检测缺列后 `ALTER`；**存量模板一律视为 active**（行为不变）
- `listTemplates(kind, status)` 支持状态过滤；新增 `activateTemplate(id)`（仅 draft 会被更新，用于幂等判定）
- `TemplateRow` 增 `status` / `sourceNote`

### 2.2 拆解管线（Python，新增 `pipeline/learn.py`）

| 路径 | 实现 |
|---|---|
| mock（无 Key） | 规则启发式：按空行分段 → 首段做 `opening`、末段含互动词做 `closing`、中间段落首句做 `structure`（≤15 字 × ≤6 条）、关键词判 `voice`（真诚分享/理性干货/犀利观点/通用） |
| 真实 | LLM 拆解；`LEARN_SYSTEM` 明确要求「**只归纳结构、不复述内容**」「structure 用短语」「无法判断就给空，不要编造」 |

两条路径共用的后处理：`_clip` 截断、条数上限、序号/项目符号剥离、名称生成（`学习：{备注}` 或 `学习：示例（MM-DD）`）。

### 2.3 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/templates/learn` | 示例 → **草稿模板**（<50 字 → 400；不存原文，只落拆解结果 + source_note） |
| POST | `/api/templates/{id}/activate` | 草稿 → 启用（不存在 404 / 内置 409 / 已启用幂等 200） |
| GET | `/api/templates?status=` | **默认 `active`**（安全默认）· `draft` · `all` |
| GET | `/api/templates/export` | 改为**只导出 active**（草稿是中间态，不纳入备份） |

### 2.4 前端（static/index.html）

- 模板库新增「✨ 从示例学习」入口 + 学习弹窗（示例文本 + 来源备注 + **合规提示**）
- 列表分三组：**草稿（待确认）** / 内置 / 我的；草稿项显示「草稿 · 待确认」徽章、来源、`AI 拆解结果，请核对后启用`
- 草稿项操作：**编辑 / 确认启用 / 丢弃**（丢弃复用 `confirm` 二次确认，文案针对草稿定制）
- 生成页选择器**只渲染 `status==="active"`** 的模板

## 4. 关键实现说明

- **UC-16 双重保障**：服务端 `GET /api/templates` **默认只返回 active**，前端选择器再按 `status==="active"` 过滤——即使前端漏改，草稿也不会进入生成选项。
- **草稿即普通模板**：草稿与已启用共用同一张表与同一套 CRUD，仅靠 `status` 区分。因此「编辑草稿」直接复用 M5 的 `PUT`，无需新代码路径（D7 实测编辑后仍为 `draft`）。
- **内置模板保护**：`activate` 对 builtin 返回 409（内置本就是 active，无需启用）；沿用 M5 的「内置不可删/不可覆盖」红线。
- **版权与隐私**：不存示例原文；prompt 要求只归纳结构、不复述内容；UI 明示「请只使用自有或已获授权的示例」。
- **mock 可演示**：无 Key 时规则拆解即可产出「看起来合理」的模板（首段/段落要点/互动结尾都能识别），保证离线可测可演示。
- **兼容性**：`GET /api/templates` 默认值变更影响面已处理——前端模板库改用 `?status=all`，M5 端到端脚本同步适配。
