### 2.2 观测破坏业务语义（FR-71 加固）—— 最严重

**缺陷**：`trace_span` 把 `yield span` 放进 `try`，在 `except` 里再次 `yield None`：

```python
try:
    with lf.start_as_current_observation(...) as span:
        yield span          # ← 业务异常在此抛出
except Exception as e:
    yield None              # ← 再次 yield → RuntimeError: generator didn't stop after throw()
```

**后果链**：业务 `RateLimited` → 被替换成 `RuntimeError` → `classify()` 归为普通 `LLMError` → **限流重试被放弃**。

**修复前复现**：
```
捕获到的异常类型: RuntimeError
期望: RateLimited
→ BUG 已复现（异常被替换）
```

**修复方式**：仅在**建立 span** 阶段容错；`yield` 后的业务异常**原样抛出**，并把异常信息交回 span 以记录真实状态。

**修复后**：
```
捕获类型: RateLimited → PASS 限流语义已恢复
_get_client 调用次数: 0 → PASS flush 未启用时零初始化
```

同时修 `flush()`：**未启用时绝不初始化客户端**（原来无条件调用 `_get_client()`）。
