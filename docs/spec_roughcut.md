# spec —— 口播粗剪：去长停顿 + 烧字幕

版本：2026-10-06（v2：参数不写死 + 两段式）　　对应 tasks：`docs/tasks_roughcut.md`　　验收：`docs/checklist_roughcut.md`

---

## 1. 背景

拍口播视频的人有一个共同的体力活：**录像里全是"死气"** —— 想词时的沉默、句子之间过长的停顿、
说错了重来的空白。这些不剪掉，成片节奏就拖。

剪它们不需要审美判断，只需要耐心：听一遍、找到沉默、切掉、再听一遍。
**这正是 AI 该替人做的那类事** —— 规则明确、错了肉眼可见。

而字幕更纯粹是体力活：把说的话一个字一个字打上去，还要对时间轴。

现状：项目已有 `剪辑单`（给抖音/B站成片的文字建议）和 `音视频入料`（视频→文字），
但**没有一步是把视频真的剪出来**。

## 2. 目标用户

**现阶段只有作者本人**：一个会写稿、会拍口播、但不想为剪辑学一套软件的人。

明确不服务陌生人 —— 因此**不做**安装引导、跨平台脚本、降级打磨。
（将来若要给别人用，那是另一个 spec。）

## 3. 能力清单（一句话一条）

1. 给一个本机视频文件，产出一个**剪掉长停顿**的视频
2. **"多长的沉默算停顿"必须可改** —— 不同人语速/口播习惯差别很大，没有普适值
3. 对**剪后**的视频自动转写，产出带时间戳的字幕
4. 把字幕**烧进画面**（中文）
5. **字幕样式必须可改**（字体/字号/颜色/描边/位置）—— 审美是人的事，不是程序的事
6. 同时导出一份**独立字幕文件**（供后续拿去别的工具精修）
7. 打印一份**"剪了什么"的摘要**：剪了几段、各在哪、剪掉多少秒、剪后时长
8. **默认两段式**：先把"打算怎么剪"给你看（哪几段、剪完多长、当前用的是哪些参数），
   **你确认或改了参数重算之后，才真的动手剪**
9. 能**预览字幕样式**（渲染一帧给你看长什么样），不用等整片渲完才发现字号不对
10. 前置条件不满足时**大声失败**：文件不存在 / 没有音轨 / 缺 ffmpeg / 缺 ASR —— 明确报错，绝不静默产出一个坏视频

## 4. 非功能要求

- **全程本地**：不上传任何数据；ASR 用本地模型（沿用 ADR-017 的数据边界）
- **不引入云服务**，不引入 Node
- **速度**：一条 1 分钟以内的口播视频，端到端应在几分钟内完成（实测 ASR 约 0.2x 实时）
- **可单独重跑某一步**：中间产物落盘保留，调参时不必从头再来
- **确定性**：同一输入 + 同一参数 → 同样的剪点（不引入随机性）
- **参数来源有明确优先级**（见 §5），且**任何一项都不能是"改不了"的
- **非交互模式**：确认环节可以一键跳过，供端到端脚本/批处理使用

## 5. 设计骨架

```
探测 → 找停顿 → 【给你看：剪点 + 当前参数】 → 你确认/改参 → 剪 → 转写 → 出字幕 → 烧字幕 → 出报告
                      ↑ 这一段是默认行为，不是可选项
```

**关键决定一：先剪，再转写。**

为什么这条重要：如果先转写再剪，字幕的每个时间戳都必须**重新映射**到剪后的时间轴上
（剪点之前的偏移、之后的累加），这是一整块容易写错的逻辑。
反过来先剪再转写，时间戳**天然就是剪后时间轴上的**，映射逻辑直接消失。

**关键决定二：所有"值"都外露，且优先级固定。**

```
内置默认  <  配置文件（长期生效，改一次管很久）  <  命令行参数（临时覆盖，单次生效）
```

用户的意图应该是**能被表达出来**的，而不是被程序猜。默认值只负责"第一次跑不用查文档"。

**其它骨架决定：**

- **剪的动作交给 ffmpeg**（一条表达式搞定所有剪点），不自己解码/编码视频
- **ASR 复用项目已有的本地转写适配层**，只补一个"要时间戳"的入口
- **字幕渲染交给 ffmpeg 的 libass**，不自己画字
- **中间产物保留**（找停顿的结果、剪后视频、字幕文件），因为调参是主要使用场景
- **确认环节能看到"代价"**：不只报段数，还要报"剪完从 X 秒变 Y 秒"——
  这是人做决定真正需要的信息

## 6. Out of Scope（本版不做）

- **去口癖/重复词**（"呃"、"然后然后"）—— 需要词级时间戳，是另一个能力
- **背景音乐存在时的"伪静音"**：有 BGM 的素材里没有真正静音，本版不处理（会如实报"没找到停顿"）
- BGM 卡点、转场、封面帧、画面美化
- 横屏转竖屏 / 改分辨率 / 改码率（**保持原样，只剪时长**）
- 多轨、多机位、批量处理
- 接进 Web 工作台（先把脚本跑顺）
- **剪点的手动微调**（比如"这一段我不想剪"）—— 本版只做到"整体参数可调 + 确认/放弃"，
  逐段勾选留到下一版
- 跨平台验证（只在 Windows 本机验）
