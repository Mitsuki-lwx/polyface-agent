# M7-1 统一资产库 — 任务书

日期：2026-10-06 · 上游：`docs/71` 产品路线再评估 §3 · `docs/08` **ADR-021**

---

## 1. 为什么做这个

`docs/71` §1 的实测结论：现在的"素材库"只是 `GET /api/materials` 的一个列表，
`material` 表**零资产关联**。而多模态与剪辑都要有东西可挂：图片、音频、视频、时间线。

> 没有资产层，"越用越懂你"永远只是 prompt 里的一句话，不是数据事实 —— 而那是 `docs/02` 写的护城河。

**它排第一的理由**：这是唯一一块"后面所有东西都要往上放"的地基。

## 2. 范围

### In

| # | 项 |
|---|---|
| 1 | **数据模型**：`asset` + `asset_link` 两张表（见 `docs/73` §2） |
| 2 | **内容寻址落盘**：`{media}/assets/<sha256前2>/<sha256>.<ext>`，重复上传天然去重 |
| 3 | **API**：列表（筛选/搜索/分页）/ 详情 / 上传 / 原文件下载 / 关联 / 删除 |
| 4 | **自动登记**：封面生成成功 → 登记为 `image/generated` 并 link 到该 draft；音视频入料上传 → 登记为 `video|audio/upload` |
| 5 | **前端「素材库」面板**：列表 + 类型筛选 + 搜索 + 上传 + 预览 + 删除 + 关联数 |
| 6 | 测试与文档（四件套 + ADR-021） |

### Out（明确不在本任务）

| 不做 | 归属 |
|---|---|
| **时间线资产的实际产出**（`timeline` 类型只占位） | M10 粗剪 |
| 任务化编排（job/task + 异步） | M8 |
| 评测集 / harness | M9 |
| 资产版本管理、孤儿文件清理命令、去重的 UI 提示 | 后续 |
| 把 `material` 迁进 asset | **不做**（ADR-021 决策 1：高风险低收益） |

## 3. 关键设计决定（先定，避免实现期摇摆）

| 决定 | 理由 |
|---|---|
| **内容寻址（sha256）** | 去重变成免费副作用；"这份素材库里已有"以后可零成本实现 |
| **不搬既有文件** | 移动用户既有文件是**破坏性操作**，收益只是目录好看。`rel_path` 记相对路径，两种布局并存 |
| **`material` 表不动** | 它与 draft/facts/effects 深度耦合且测试充分；搬家是高风险低收益 |
| **删除不静默删文件** | 仅当该 sha256 再无任何记录引用时才删。与 ADR-017 的数据姿态一致 |
| **登记自动化** | 用户不该"记得去存进素材库"；封面与上传各自在既有流程里顺手登记 |
| **关联表而非外键列** | 一个资产可挂多个 owner（同一张图给多个稿件复用 —— "素材复用"的字面含义） |

## 4. 依赖与前置

- M6-1（封面产物）、FR-51（音视频入料）已交付 —— 本任务要把它们接进资产库
- 无新增 Java 依赖（sha256 用 JDK `MessageDigest`；图片尺寸解析**可选**，见 `docs/73` §5）
- 无新增 Python 依赖（本任务全在 Java + 前端）

## 5. 验收（可观测）

1. 上传同一份文件两次 → 磁盘只有**一份**文件，库里两条记录指向同一 `sha256`（或一条记录 + 复用）
2. 生成封面 → 素材库里**自动**出现该图，且关联到对应 draft
3. 音视频入料上传 → 素材库里自动出现该媒体
4. 列表支持按类型筛选与关键词搜索
5. 删除一个被引用的资产 → **解链但保留文件**；删除最后一个引用 → 文件才消失
6. 浏览器实测：能上传、能看到、能搜、能删、能预览
7. 全量测试无退化 + 变异测试 ≥1 次

## 6. 风险

| 风险 | 应对 |
|---|---|
| 大文件上传（视频几百 MB） | 沿用现有 500MB multipart 上限；sha256 流式计算，**不整份读进内存** |
| 既有文件布局与新布局并存导致路径混乱 | 一律以 `rel_path`（相对 media 根）为准，`MediaDir.resolveSafe` 统一防穿越 |
| 删除语义被误解为"回收站" | 文档写清：删记录 + 解链；文件仅在无人引用时删除 |
| 素材库面板与既有"素材历史"混淆 | 两者定位写进 UI 文案与 README：**素材历史=文本素材**，**素材库=资产** |
