## 新增能力

- **3 张表**：`effect_metrics`（效果回填，一稿多记录）/ `creator_profile`（单行 id=1）/ `retrospect_log`（聚合 insights 落库，便于二次回写）
- **REST API**：
  - `POST /api/drafts/{id}/effect` — 录入效果
  - `GET /api/drafts/{id}/effects` — 某稿全部效果（倒序）
  - `GET /api/effects?draft_id=` — 全部效果（聚合查询用）
  - `GET /api/retrospect?platform=&domain=` — 聚合洞察报告
  - `GET /api/profile` / `PUT /api/profile` — 画像读写
- **Python 端**：`GenerateRequest.creator_profile` + `retrospect_hints`；brief/draft 真实模式 prompt 注入；mock 模式在 rationale/body 显式标记
- **MaterialController 编排**：调 `/api/materials/{id}/generate` 时自动拉画像+回写最近 10 条 retro_log 进 Python 请求，前端零改动
- **复盘自动持久化**：`GET /api/retrospect` 返回的 insights 按 `(platform_code, insight)` 去重写入 retro_log → 下次生成自动引用
- **SPA 工作台**（同文件 `static/index.html`，零构建）：
  - 左侧栏新增「④ 创作者画像」卡（4 字段 + 保存）
  - 主区右上「📊 复盘报告」Tab（数据不足时给引导文案）
  - 「📈 录入效果」按钮 → 弹窗：选关联 draft + 录四指标 + 发布日期 + 备注
  - 每个 draft 卡片右上「📈 录效果」按钮（预选 draft_id）

## 关键实现说明

- **复盘聚合**：完全离线规则，启发式（互动分 = likes + comments*3 + favs*2；样本≥6 时对比 top3/bottom3 差距给"避雷信号"）；不调 LLM，零成本、可重复。
- **去重持久化**：避免每次 GET retrospect 都灌重复 insights；按 insight 字符串去重。
- **mock 模式可视化**：brief.rationale 与 draft.rationale 都明确显示"创作者画像:领域=X/声音=Y/受众=Z" + "已应用 N 条历史经验"，方便离线演示闭环。
- **真实模式**：brief/draft prompt payload 增加 `creator_profile` 与 `retrospect_hints` 字段，由 LLM 自然融入生成。
- **数据流**：录入效果 → GET 复盘 → 自动持久化 → 二次生成自动带上。
