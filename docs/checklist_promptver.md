## 变异测试（2026-10-17，两条都做了）

| 变异 | 结果 |
|---|---|
| 把哈希改成**整个文件哈希** | ✓ `test_fingerprint_is_per_prompt_not_per_file` 失败 |
| 把 `prompt_fp` 写成**常量** `"constant0000"` | **第一次没抓住** ✗ → 补测试后 ✓ 抓住 |

### 第二次变异**暴露了一个真实的测试缺口**（这是变异测试的价值所在）

原来的断言只有"非空 / 12 位 / 彼此不同"—— **常量全都能过** ✗。
补了 `test_fingerprint_equals_independently_recomputed_hash`（**独立重算一遍 sha256 比对**），
重跑变异 → 抓住 ✓。

**教训**：验"形状"（长度/非空/互异）不等于验"值"。形状类断言对"换成常量"这种变异**完全无效**。

### 另记一个测试设计坑

CLI 是**独立进程**，`monkeypatch.setattr(templates_dir, …)` **传不进去** ✗（第一次这么写，
测试红了）。改用 `POLYFACE_USAGE_FILE` **环境变量**把子进程的数据目录指到临时目录 ✓。
