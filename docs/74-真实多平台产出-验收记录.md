## 十一、骨架容错回填（2026-11-09）

**问题**：槽位只要有一点不完美（该段没声明它 / 表层措辞对不上）就**留白**，然后 `{{` 残留
被闸门判死 → **整篇丢弃** ✗。实测 1/3 平台死在这里。

**改动**（`skeleton._assemble_unit` 分级）：

| 情况 | 原来 | 现在 |
|---|---|---|
| 事实序号不存在 | 硬违规 | **硬违规**（真幻觉，无法回填）✓ |
| 表层为空 | 硬违规 | **硬违规**（没有值可回填）|
| 序号存在，但**该段没声明它** | 硬违规 → 整篇丢 ✗ | **回填 + 软提醒** ✓ |
| 序号存在，但**表层措辞对不上** | 硬违规 → 整篇丢 ✗ | **回填 + 软提醒** ✓ |

**安全性没丢** ✓ —— 回填的是**事实图层面的值** ✓，真幻觉仍被**数字门 G3** 拦住：

```
facts = ["卡里就剩两万三。"]      骨架：亏了{{n:1|199}}
hard: ['段1 出现声明依据之外的数字「199」']   ← G3 拦住了 ✓
soft: ['段1 槽位 …… 表层「199」找不到逐字依据（已回填；数字仍由 G3 复核）']
```

两道门分工：**槽位门管"值从哪来"**（放宽为回填），**数字门管"值对不对"**（不放宽 ✗）。

### 测试
