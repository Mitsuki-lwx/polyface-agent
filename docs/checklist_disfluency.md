# checklist —— 口播去冗余

spec：`docs/spec_disfluency.md`　　tasks：`docs/tasks_disfluency.md`

每一项都可勾选、可观测。**默认值 ≠ 写死的值**：每条可调参数都要有一条"改了它，行为确实变了"。

---

## 1. 词级转写（T1）

- [ ] 返回的 words 非空，且 `start`/`end` 单调递增（无逆序）
- [ ] words 覆盖的区间与段级时间戳一致（首尾差 < 0.5s）
- [ ] 没有词级时间戳的 ASR 后端 → **明确报错**，不是静默返回空 words

## 2. 规则判定（T2/T3）

- [ ] 完全重复的相邻两句 → 标出后一句，`kind=repeat`
- [ ] 半句重起（「我们今天要讲的」→「我们今天要讲的是」）→ 标出前一句，`kind=restart`
- [ ] 口头语独立成词（「那个」单独出现）→ 标出，`kind=filler`
- [ ] **口头语不误伤**：「那个人」「那个年代」里的「那个」**不被标**
- [ ] 换措辞的重说 → 标为**低置信**（留给模型复核），不是直接剪
- [ ] 两件不同的事（相似度低于阈值）→ **不标**
- [ ] 每条判定都带 `evidence`（相似度数值 / 命中的词 / 前后句原文）
- [ ] 改相似度阈值 → 标出的条数确实变化

## 3. 模型复核（T4）

- [ ] 模型返回"是"→ 该段标为重复且 `source=llm`
- [ ] 模型返回"否"→ **不标**（模型可以否决规则的疑点）
- [ ] 模型抛异常/超时 → `llm_skipped=true`，**流程继续**（降级到纯规则），报告里标明
- [ ] 发给模型的内容**只包含可疑句对**，不含全文（可观测：请求体的长度/句数）
- [ ] 模型返回里**没有时间戳**（时间戳一律由程序从原句对取）—— 防模型瞎编时间

## 4. 剪点合并（T5）

- [ ] 重叠的冗余/停顿区间 → 合并后**不重复**
- [ ] 相邻（间隔小于 1 帧）的区间 → 接上
- [ ] 低于最短时长的片段 → 丢弃（可观测：报告里不计入）
- [ ] 边界回退后**不侵入语音**（回退到语音边界 + 余量）
- [ ] 合并后剪点按时间**升序**排列，无交叠

## 5. 参数（T6）

- [ ] 四类**各有独立开关**，关掉某类 → 该类不再出现在方案里
- [ ] 口头语词表**在配置文件里**，改它 → 判定结果变
- [ ] 命令行参数**覆盖**配置文件
- [ ] 不填任何参数 → 用内置默认，能跑通
- [ ] `grep` 代码：没有任何一个可调值是**只能改代码才能变**的

## 6. 落盘与可解释（T7）

- [ ] 判定结果落盘（区间/类别/依据/来源）
- [ ] 同一输入重跑，**不重新转写**（可观测：第二次耗时显著短）
- [ ] 报告逐条列出"剪了哪几段 + 为什么 + 来源（规则/模型）"
- [ ] 报告汇总：各类剪了几段、共剪多少秒、剪前/剪后时长

## 7. 接入主流程（T8）

- [ ] 发起粗剪 → 方案里**同时**含停顿与冗余剪点（一份清单，不是两次剪）
- [ ] 方案里每条冗余都能看到**理由**
- [ ] 确认后成片；改参重算 → 方案确实变
- [ ] 非交互模式一键跳过确认，能跑通
- [ ] UI：粗剪面板能开关四类，能看理由列表

## 8. 安全底线（**最重要**）

- [ ] 冗余判定**只剪连续语音内部**的片段，绝不剪掉整段开头/结尾的独立内容
- [ ] 边界回退**宁可少剪**：剪错一句话的代价 > 多留 0.3 秒
- [ ] 误剪可复核：报告能定位到"剪掉的那段原文是什么"
- [ ] 中间产物保留 → 误剪后能改参重跑，不必重拍

## 9. 端到端（T9，**必须真素材**）

- [ ] 一份真实口播素材（含停顿 + 口误 + 重复 + 口头语）→ 走完整链路出成片
- [ ] 四类各自抓到 ≥1 处（若素材里确实有）
- [ ] **误剪的逐条列出**（报忧不报喜）
- [ ] 剪点边界听感正常（无半个字被剪、无爆音）
- [ ] 原始输出（方案/报告/时长）贴进本文件
- [ ] 全程本地（除模型复核那一步的文本外）
