## 2. 调研产出（核心价值）

### 2.1 五个平台的官方来源

| 平台 | 官方来源 |

### 2.2 最有价值的四个发现

1. **AI 生成内容须显著标识**（知乎协议 §二.06 明文 + 小红书公约 2.0）→ 已落为 `limits.ai_disclosure` 结构化字段。**本工具产出的是 AI 辅助稿，发布时应提示用户标注。**
2. **「标题党」是全平台明文红线**，且各有具体定义（B站明列 5 类含「故意营造悬念」；微信明列 5 类含「故意隐藏关键信息」）。
3. **诱导互动有明确边界**：抖音明禁「故意不讲重点、内容不完整诱骗观看」；微信明禁「不转不是中国人」类话术 → 直接影响 `hooks` 写法。
4. **抖音官方把「单图+大量文字」「模版感强的图片轮播」列为低质** → **对 FR-52 图文成片有直接约束**，设计时须避免。

详细见 `docs/33-平台DNA调研报告.md`。

## 3. 对照验证

### 3.1 prompt 层面（零成本、确定性强）

```
旧 DNA → prompt  964 字符
新 DNA → prompt 1419 字符（+47%）
新增 22 行 / 删除 14 行
```

新增的约束均有官方依据，例如：
```
+ "严禁题文不符、夸大：社区规范将「标题党、图文不符」列为不友好内容"
+ "制造对立：性别/地域/职业/兴趣群体贴标签、放大差异、煽动矛盾（社区公约 2.0 核心倡导）"
+ "虚假人设与伪造数据：财富/学历/收入/情感经历造假，伪造口碑，伪装素人，AIGC 造假"
```
**关键设计**：`sources`/`verify`/`distribution` 等元数据**不注入 prompt**（避免无谓 token 消耗），只有对生成有约束力的字段进 prompt。

### 3.2 真实 LLM 生成

新 DNA 下真实生成（小红书）：
```
mock=False 耗时=250s（期间多次 429 限流）
标题候选: ['裸辞后靠写作月入3万，我的关键动作是每周复盘',
           '从月入0到3万：写作变现真正拉开差距的是每周复盘']
标签: ['自由职业','写作变现','每周复盘','裸辞生活','副业干货','成长自律']  ← 6 个，符合 count_max=6
QA passed: False | issues: 2
```

**诚实评估**：
- ✅ 产出正常，标题体现 DNA 的「数字+结果」规则，标签数量正确
- ⚠️ **QA 未通过（2 issues）**：mock 模式下同素材 QA `passed=True`，说明 QA 逻辑未被 DNA 改动破坏；真实模式的 issues 属 **LLM 生成内容**问题（当时伴随 429 限流与降级）
- ⚠️ **未做严格的 A/B 真实对照**（旧 DNA 各跑 N 次）：受上游额度限制（单次 100~250s 且频繁 429），本任务只做了 **prompt 层对照 + 新 DNA 单次真实验证**

## 4. 过程中发现并修复的三个问题

重建过程暴露了 DNA 与管线之间的**隐性契约**，值得记录：

| # | 问题 | 原因 | 修复 |
|---|---|---|---|
| 1 | `style`/`structure_template` 等列表字段混入 `ref:/note:` 的 dict | 我为标注来源在**会注入 prompt 的字段**里用了映射结构 | 全部改为纯字符串，来源用注释 + `sources[].covers` 承载 |
| 2 | 剪辑单（FR-50）失效，`clip_sheet=None` | 漏了原有字段 **`video_native`**（不在我的 schema 扩展清单里） | 补回 douyin/bilibili 的 `video_native: true` |
| 3 | 漏了原有字段 **`viral_logic`** | 同上 | 5 平台全部补回 |

**问题 2/3 是被单测抓出来的**（`test_video_platform_returns_clip_sheet` 失败）——正好印证"改动后必须跑回归"的必要性。已在 spec 之外额外做了**字段完整性检查**（比对代码中实际读取的所有 DNA 字段）。

## 5. 残余项与不确定项

### 待核实（已在各 YAML 的 `verify.todo` 标注）
- 小红书：标签数上限、视频/图片数上限
- 抖音：标题 55 字、文案 2200 字、视频 900s
- 微信：标题 64 字、摘要 120 字
- 知乎：标题 100 字；好物推荐细则（第三方来源，未写入 specs）
- B站：标题 80 字、简介 2000 字

### 未做
- [ ] **严格 A/B 真实对照**（旧 vs 新各多次）——受上游额度限制，仅做 prompt 对照
- [ ] 真实模式 QA 未通过的原因深挖（需在额度宽裕时复现）
- [ ] 前端展示 `display_name` / `ai_disclosure` 提示（建议后续做：生成结果页提示"发布时请标注 AI 辅助"）
- [ ] DNA 定期复核机制（建议每季度；YAML 已记 `updated_at`）

### 边界（避免过度承诺）
DNA 是**改写输入约束**，不保证流量结果。平台推荐算法不公开，内容质量、账号权重、发布时间等影响更大。
