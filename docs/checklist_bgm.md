# checklist —— 带 BGM 的口播也能剪

spec：`docs/spec_bgm.md`　　tasks：`docs/tasks_bgm.md`

---

## 1. VAD 找停顿（T1）

- [ ] 同一段音频，**加 BGM / 不加 BGM** → 停顿区间**相同**（这是本 spec 的核心断言）
- [ ] 对照旧路径：带 BGM 时旧路径 0 段，新路径能找出停顿
- [ ] 语音空隙低于阈值 → **不算**停顿
- [ ] 已有转写段时**不重复转写**（可观测：耗时显著短）
- [ ] 边界落盘，可复核

## 2. BGM 检测（T2）

- [ ] 真实带 BGM 素材 → `has_bgm=True`
- [ ] 纯口播（无 BGM）→ `has_bgm=False`
- [ ] 报告里能看到"有没有 BGM"（不是让用户猜为什么剪点少）

## 3. 降噪兜底（T3）

- [ ] monkeypatch 掉 ASR → 走降噪路径，`source=="denoise"`
- [ ] **报告里写明用了哪条路**（不静默降级）
- [ ] 两条路都能给出剪点（降噪路径在带 BGM 素材上**允许**给不出 —— 但要说明）

## 4. 抽伴奏（T4）

- [ ] 抽出的片段确实来自**无人声窗口**（可观测：与源比对该区间）
- [ ] 选的是**最长**的窗口
- [ ] 短于 `min_loop_sec` 的窗口**不用**
- [ ] **整条都在说话 → 明确失败**，不硬凑一段伴奏

## 5. 铺伴奏（T5）

- [ ] 产物时长 = 剪后视频时长（伴奏铺到等长）
- [ ] 接缝处**无爆音**（波形峰值不突变）
- [ ] 改交叉淡化长度 → 接缝确实变化
- [ ] 人声/伴奏电平可调；改它 → 混音电平确实变

## 6. 参数（T6）

- [ ] 关掉 `bgm_aware` → **回到纯 silencedetect 的旧行为**（可对照）
- [ ] 六个新增值各自可调，改一个 → 行为变
- [ ] 不填任何值 → 默认能跑
- [ ] `grep` 代码：没有"只能改代码才能变"的值

## 7. 两段式（T7）

- [ ] 方案里有：**有没有 BGM** + **用了哪条判据** + **BGM 怎么处理** + **剪后时长**
- [ ] 方案里**如实写明**"BGM 变成循环、不是原编曲"（代价不能藏）
- [ ] 确认后才剪；改参重算 → 方案确实变

## 8. 端到端（T8，**必须真素材**）

- [ ] 带 BGM 的真实口播 → 出方案 → 确认 → 出成片
- [ ] 剪点逐条核对（对着转写/波形）
- [ ] **BGM 连续**：听 + 看频谱（剪点处不应有能量断口）
- [ ] 人声没被剪掉半个字
- [ ] **剪错的、接缝听得出的一律列出来**（报忧不报喜）
- [ ] 原始输出（方案/报告/时长/电平）贴进本文件

## 9. 文档（T9）

- [ ] 新 ADR 记录"为什么重建而不是人声分离"（含 torch 体积这个关键权衡）
- [ ] `spec_roughcut.md` 补"BGM 场景"一节
- [ ] README FAQ 补"带 BGM 的素材会怎样"
- [ ] `grep` 确认文档与实现一致

## 10. 变异测试

- [ ] 把停顿判据改回"音量门限" → §1 的"有无 BGM 结果相同"**变红** → 还原
- [ ] 去掉"没有无人声窗口就失败" → §4 的断言**变红** → 还原
- [ ] 把降级改成静默（不标记 source）→ §3 的"写明哪条路"**变红** → 还原
