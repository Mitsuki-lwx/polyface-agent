- 版本：v1.0（开发前置文档补录）· 关联：docs/05 SRS
- 用途：把功能需求落到**可执行验收**，M3 起的每个功能按 UC 编号开发与验证

---

## 1. 角色（Actors）

| 角色 | 说明 |
|---|---|
| 创作者（主角色） | 单机单用户，直接面对 Web 工作台 |
| LLM 服务（系统角色） | Python 侧，执行解析/策略/成稿/自评 |
| 平台发布渠道（外部） | 创作者自己把稿件复制到平台（工具不自动发布） |

## 3. 用例详情

### UC-01 新建素材并解析
- 前置：应用已启动。
- 主流程：
  1. 创作者粘贴文本（或选长文/口播稿/大纲/笔记类型）；
  2. 点击"解析"；
  3. 系统返回 core_message/tone/audience/facts 摘要。
- 异常：空文本 → 校验提示；LLM 服务不可用 → 502 与 mock 提示。
- **验收**：`POST /api/materials` 返回 id + structured.facts 非空；历史可查（✅ M1 已实现并有测试）。

### UC-02 审阅/修正事实清单
- 前置：UC-01 完成。
- 主流程：创作者在事实清单中增/删/改条目 → 保存（覆盖后续生成依据）。
- **验收**：修改后再次生成，正文只使用修改后的事实集（防幻觉依据随之更新）。

### UC-03 勾选平台一键生成
- 前置：素材已解析（UC-01）。
- 主流程：勾选平台（≥1）→ 点击生成 → 并行执行 brief/draft/qa → 展示每平台成稿状态。
- 异常：未勾选平台 → 提示至少选一个；未知平台 → 400（提示可用列表）；部分失败 → 展示失败平台。
- **验收**：
  - `POST /api/materials/{id}/generate` 返回逐平台 draft，状态为 `qa_passed` 或 `needs_review`；
  - 单平台成稿字段齐备：titles≥1、body、tags、rationale（✅ M2 已实现）；
  - 多平台并行耗时 ≈ 最慢平台（非累加）。

### UC-04 查看各平台成稿与改写说明
- **验收**：每个平台卡片展示 标题候选/正文/标签/封面建议/互动语/**改写说明(rationale)**，说明引用了该平台 DNA 要点。

### UC-05 编辑/复制/导出
- **验收**：稿件可全文编辑；一键复制；导出平台化排版后的 txt/md（复制格式与平台要求一致，如小红书换行、抖音脚本分镜）。

### UC-06 QA 报告与重跑
- **验收**：
  - 展示规则校验与 LLM 自评 issues/warnings；
  - 未通过稿件可手动"重跑 QA"或"带反馈重写"；
  - 故意在正文加无依据数字 → 被 warning 拦截（回归测试已有）。

### UC-07 配置 LLM
- **验收**：设置页可填 base_url/key/model；"测试连通"返回模型可用；Key 不落日志/不落库/不入 git。

### UC-08 素材历史管理
- **验收**：素材列表按时间倒序，显示各平台稿数；可打开、可再次"仅改平台"复用；可删除（级联删稿）。

### UC-09 回填发布效果
- **验收**：每个已确认稿件可录入 播放/赞/藏/评 或粘贴截图说明；数据绑定 draft 与素材。

### UC-10 复盘报告
- **验收**：
  - 系统汇总该素材/周期效果，产出洞察（哪个平台/哪类标题/哪类内容有效）；
  - 洞察回写创作者画像；下次生成前提示"已采纳 N 条历史经验"。

### UC-11 获取视频平台剪辑单（AI 剪辑 A 阶段）
- 前置：素材已生成抖音/B站成稿（含口播稿）。
- 主流程：选择"生成剪辑单" → 系统按稿产出 分镜时间轴/画面建议/字幕断句/BGM·转场提示 → 可在界面查看与导出。
- **验收**：剪辑单字段齐备（编号/时长区间/画面/字幕/声音备注），可直接照着剪；随稿复制导出。
- 里程碑：M3。

### UC-12 视频/音频转文字入料（C 阶段）
- 前置：本机有视频/音频文件路径。
- 主流程：选择文件 → 转录为口播稿文本 → 转成素材走 understand 解析 → 继续多平台改写。
- **验收**：转录文本可编辑后再解析；转录稿进入素材历史；无外部上传。
- 里程碑：M3.5。

### UC-13 本地自动成片（B 阶段，B1+B2）
- 前置：有图片素材（B1）或有原始录像（B2）。
- 主流程：
  - B1：选择图片目录 + 文案/TTS → 按剪辑单拼合 → 输出 MP4；
  - B2：选择原始录像 → 自动去停顿（silence）→ 本地转写字幕烧录 → 分镜/可选卡点 → 初剪 MP4。
- **验收**：B1 产出可播放 MP4；B2 输出的初剪片语音连贯、字幕与口播同步；**仅本地生成，不自动发布**；失败任务可重跑；保留"人工再审一版"流程（AI 预剪定位）。
- 里程碑：M5+ 专项。

### UC-14 创建/管理我的内容模板
- 前置：无（新用户可从预置模板起步）。
- 主流程：新建模板 → 填 名称/开头句式/正文结构/结尾互动/口播框架/标签偏好 → 保存；可编辑/复制/删除/导入导出。
- **验收**：模板 CRUD 生效；存储本地；导出文件可再导入（备份/共享）；导入遇同名由用户裁决。
- 里程碑：M3 基础版（字段表单）→ **M5 完整版 ✅**。

### UC-15 生成时套用模板
- 前置：已有至少 1 个内容模板 + 素材已解析。
- 主流程：生成页选"模板"（默认 DNA / 我的模板 / DNA+模板混合）→ 生成 → 稿件结构体现模板套路，但**平台字数/标签/红线限制仍被 QA 强制**。
- **验收**：同一素材用不同模板产出的结构明显不同；违规边界不被模板绕过；稿件记录模板版本。
- 里程碑：M3（生成时套用）→ **M5 完整版（版本随稿存档）✅**。

### UC-16 示例自动学习模板（学习+人工确认）
- 前置：用户有一篇自有爆款/示例片（M4 记忆系统之后提供，避免无效果数据学偏）。
- 主流程：上传示例 → 系统拆解结构参数 → 生成"草稿模板"→ **用户审阅确认后启用**；未确认不进入生成选项。
- **验收**：草稿模板可预览其结构；未确认的模板不会出现在 UC-15 选择列表；确认后可编辑。
- 里程碑：**已完成（M5b）✅** —— 示例**文本**拆解 + 人工确认启用；示例**片**（视频/音频）待 FR-51/FR-61。
