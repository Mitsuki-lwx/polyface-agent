# checklist —— 口播粗剪：去长停顿 + 烧字幕

对 `docs/spec_roughcut.md` 的可勾选验收。**一行一条，可独立判定。**
不许写「实现完整」「质量良好」这类无法判定的项。

> 状态：**未开工**（本文件先于实现写，验收时逐条勾）

---

## 1. 具体值（spec 里刻意不写的那些，在此锁定）

| 项 | 值 | 说明 |
|---|---|---|
| 停顿阈值默认值 | **0.8s** | 实测 0.3s 会把逗号处的自然停顿也剪掉（8 段），0.8s 只剪真空档（4 段） |
| 噪声门限默认值 | **-30dB** | 实测 -20~-40dB 结果几乎相同，不敏感 |
| 剪点两端保留余量 | **0.08s** | 留一点气口，否则切口很生硬 |
| 字幕字体 | **Microsoft YaHei** | 本机可用；不指定字体中文会变方块 |
| 字幕字号 | **16** | 720×1280 下实测合适 |
| 字幕颜色 / 描边 | **白字 #FFFFFF / 黑描边 #000000** | 描边宽度 2 |
| 字幕位置 | **底部居中，距底 40px** | 竖屏口播常用位 |
| ASR 模型 | **small**（沿用 `asr.py` 的默认） | 21s 音频转写 4.6s，中文可用 |

## 2. 前置与失败（**大声失败**）

- [ ] 输入文件不存在 → 报错文本里**含该路径**，退出码非 0
- [ ] 输入没有音轨 → 报错明确说"没有音轨"，**不是**报 ffmpeg 的一串日志
- [ ] 把 ffmpeg 从 PATH 摘掉 → 报错文本含安装指引
- [ ] 未安装 ASR 组件 → 报错文本含 `pip install faster-whisper`
- [ ] 以上四种错误文本**互不相同**（不能都是同一句"执行失败"）

## 3. 找停顿

- [ ] 对测试素材（含 3 处插入的长停顿）跑默认阈值 → 找到 **≥3** 段停顿
- [ ] 阈值调到 1.5s → 找到的段数 **≤** 0.8s 时的段数（单调性）
- [ ] 同一输入 + 同一参数，跑两次 → 剪点列表**逐字节相同**
- [ ] 对"有 BGM 的素材"（无真静音）→ 报"未找到停顿"并**正常退出**（不产出空视频）

## 4. 剪

- [ ] 剪后时长 ≈ 原时长 − 摘要里报的剪掉秒数（**误差 ≤ 0.2s**）
- [ ] `ffprobe` 报的剪后时长与摘要里的数字**一致**
- [ ] 剪后视频音画同步：抽 2 帧（靠前/靠后）比对，画面内容与对应音频位置不漂移
- [ ] 剪点附近没有明显的画面撕裂/黑帧

## 5. 转写与字幕

- [ ] 转写文本与台词一致（人名同音错可接受，**语义不能跑偏**）
- [ ] 字幕片段的起止时间**落在剪后时间轴内**（不出现大于剪后时长的时刻）
- [ ] 独立字幕文件存在、非空、能被 ffmpeg `subtitles` 滤镜直接读取
- [ ] **烧字幕抽帧能看到正确中文**（不是方块、不是乱码）
- [ ] 字幕不压画面底边（距底 40px 生效）

## 6. 摘要

- [ ] 摘要打印：段数 / 每段起止 / 剪掉总秒数 / 剪后时长 —— 四项齐全
- [ ] 剪点文件（机器可读）落盘且内容与打印一致

## 7. 端到端（**至少一条**）

- [ ] 一条命令：`输入 talking.mp4 → 输出 out.mp4`，**不加任何参数**即跑通
- [ ] 跑完同时得到：剪后视频 + 独立字幕文件 + 剪点文件，三者都在
- [ ] 用**同一份素材**换阈值跑第二次，输出时长**明显不同**（证明阈值真的起作用）
- [ ] 全程**不出网**（断网可跑）

## 8. 变异测试（至少 1 次）

- [ ] 故意把剪点条件表达式改坏（如把 `not(between(...))` 写成 `between(...)`）
      → 确认端到端脚本**变红** → 还原 → 复绿
- [ ] 记录变异前后的实际数字（时长、段数）

## 9. 诚实边界（验收时必须如实填）

- [ ] 本次用的是**合成素材**（TTS 合成 + 纯色画面），**不是真实口播录像** —— 必须写明
- [ ] 未验证：真实摄像机的噪声底噪、真实口播的语速/口癖、背景音乐、方言
- [ ] 未验证：长视频（>5 分钟）的耗时与内存
