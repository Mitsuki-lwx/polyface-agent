# checklist —— 口播粗剪：去长停顿 + 烧字幕

对 `docs/spec_roughcut.md` 的可勾选验收。**一行一条，可独立判定。**
不许写「实现完整」「质量良好」这类无法判定的项。

> 状态：**未开工**（本文件先于实现写，验收时逐条勾）

---

## 1. 默认值表（**每一项都必须能被覆盖**）

这些是"第一次跑不用查文档"的起点，**不是写死的值**。
验收时不只要看默认值对不对，更要看**改得动**（§2 专测这个）。

| 参数 | 默认值 | 依据 |
|---|---|---|
| 停顿阈值 | **0.8s** | 实测 0.3s 会连逗号处的自然停顿一起剪（8 段），0.8s 只剪真空档（4 段） |
| 噪声门限 | **-30dB** | 实测 -20~-40dB 结果几乎相同，不敏感 |
| 剪点两端余量 | **0.08s** | 留一点气口，否则切口生硬 |
| 字幕字体 | **Microsoft YaHei** | 本机可用；不指定字体中文会变方块 |
| 字幕字号 | **16** | 720×1280 下实测合适 |
| 字幕颜色 / 描边 | **白 #FFFFFF / 黑 #000000** | 描边宽度 2 |
| 字幕位置 | **底部居中，距底 40px** | 竖屏口播常用位 |
| ASR 模型 | **small** | 21s 音频转写 4.6s，中文可用 |

## 2. 参数可改（**本轮的核心验收**）

- [ ] `--help` 能列出**全部**可调参数及其默认值（数一数，与 §1 表对得上）
- [ ] 改**配置文件** → 不传任何命令行参数也生效
- [ ] 命令行传参 → **覆盖**配置文件
- [ ] 把停顿阈值从默认改成 1.5s → 剪后时长**明显变长**（剪得少了）
- [ ] 改字幕字号 → 抽帧结果**确实不同**（不是改了个没人读的变量）
- [ ] 改字幕位置/颜色 → 抽帧结果**确实不同**
- [ ] 代码里搜不到"改不了"的魔法数字：§1 表里的每个值都能从配置或命令行到达

## 3. 两段式确认

- [ ] 默认跑 → **不产生任何输出文件**，只打印预览（剪点 / 剪前时长 / 剪后时长 / 本次生效参数）
- [ ] 预览里能看到**"剪完从 X 秒变 Y 秒"**（不是只有段数）
- [ ] 回车 → 继续执行并产出文件
- [ ] 输入新阈值 → **用新值重算并再次预览**（不退出、不直接开剪）
- [ ] 输入放弃 → 退出码 0 且**无任何副作用**
- [ ] 带非交互开关 → 完全不问，直接执行（供脚本使用）

## 4. 前置与失败（**大声失败**）

- [ ] 输入文件不存在 → 报错文本里**含该路径**，退出码非 0
- [ ] 输入没有音轨 → 报错明确说"没有音轨"，**不是** ffmpeg 的一串日志
- [ ] 把 ffmpeg 从 PATH 摘掉 → 报错文本含安装指引
- [ ] 未安装 ASR 组件 → 报错文本含 `pip install faster-whisper`
- [ ] 以上四种错误文本**互不相同**（不能都是同一句"执行失败"）

## 5. 找停顿

- [ ] 对测试素材（含 3 处插入的长停顿）跑默认阈值 → 找到 **≥3** 段停顿
- [ ] 阈值调到 1.5s → 段数 **≤** 0.8s 时的段数（单调性）
- [ ] 同输入同参数跑两次 → 剪点列表**逐字节相同**
- [ ] 对"有 BGM 的素材"（无真静音）→ 报"未找到停顿"并**正常退出**（不产出空视频）

## 6. 剪

- [ ] 剪后时长 ≈ 原时长 − 摘要里报的剪掉秒数（**误差 ≤ 0.2s**）
- [ ] `ffprobe` 报的剪后时长与摘要数字**一致**
- [ ] 剪后视频音画同步：抽靠前/靠后各一帧，画面内容与对应音频位置不漂移
- [ ] 剪点附近没有明显画面撕裂/黑帧

## 7. 转写与字幕

- [ ] 转写文本与台词一致（人名同音错可接受，**语义不能跑偏**）
- [ ] 字幕片段的起止时间**落在剪后时间轴内**（不出现大于剪后时长的时刻）
- [ ] 独立字幕文件存在、非空、能被 ffmpeg `subtitles` 滤镜直接读取
- [ ] **烧字幕抽帧能看到正确中文**（不是方块、不是乱码）
- [ ] 字幕不压画面底边（距底 40px 生效）
- [ ] 字幕预览模式只出一张图，**不渲染整片**

## 8. 摘要

- [ ] 摘要打印：段数 / 每段起止 / 剪掉总秒数 / 剪后时长 / 本次生效参数 —— 五项齐全
- [ ] 剪点文件（机器可读）落盘且内容与打印一致

## 9. 端到端（**至少一条**）

- [ ] 一条命令：`输入 talking.mp4 → 输出 out.mp4`，**不加任何参数**（非交互）即跑通
- [ ] 跑完同时得到：剪后视频 + 独立字幕文件 + 剪点文件，三者都在
- [ ] 用**同一份素材**换阈值跑第二次 → 输出时长**明显不同**
- [ ] 全程**不出网**（断网可跑）

## 10. 变异测试（至少 1 次）

- [ ] 故意把剪点条件表达式改坏（如 `not(between(...))` 写成 `between(...)`）
      → 确认端到端脚本**变红** → 还原 → 复绿
- [ ] 记录变异前后的实际数字（时长、段数）

## 11. 诚实边界（验收时必须如实填）

- [ ] 本次用的是**合成素材**（TTS 合成 + 纯色画面），**不是真实口播录像** —— 必须写明
- [ ] 未验证：真实摄像机底噪、真实语速/口癖、背景音乐、方言
- [ ] 未验证：长视频（>5 分钟）的耗时与内存
