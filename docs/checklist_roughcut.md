## 1. 默认值表（**每一项都必须能被覆盖**）

这些是"第一次跑不用查文档"的起点，**不是写死的值**。验收时不只要看默认值对不对，更要看**改得动**（§2 专测）。

| 参数 | 默认值 | 依据 |
|---|---|---|
| 停顿阈值 | **0.8s** | 实测 0.3s 会连逗号处的自然停顿一起剪（8 段），0.8s 只剪真空档（4 段） |
| 噪声门限 | **-30dB** | 实测 -20~-40dB 结果几乎相同，不敏感 |
| 剪点两端余量 | **0.08s** | 留一点气口，否则切口生硬 |
| 字幕字体 | **Microsoft YaHei** | 本机可用；不指定字体中文会变方块 |
| 字幕字号 | **16** | 720×1280 下实测合适 |
| 字幕颜色 / 描边 | **白 #FFFFFF / 黑 #000000** | 描边宽度 2 |
| 字幕位置 | **底部居中，距底 40px** | 竖屏口播常用位 |
| ASR 模型 | **small** | 21s 音频转写 4.6s，中文可用 |

## 3. 两段式确认

- [x] 默认跑（`--dry-run`）→ **不产生任何输出文件**，只打印预览（§3a）
- [x] 预览里有**「剪完从 X 秒变 Y 秒」**（§3b：`剪掉共 8.54s：24.60s → 16.06s（省 34.7%）`）
- [x] 回车 → 继续执行并产出文件（交互路径；`--yes` 走同一条执行路径）
- [x] 输入新阈值 → **重算并再次预览**（循环回到预览，不直接开剪）
- [x] 输入 `q` → 退出码 0 且**无任何副作用**（§3c）
- [x] `--yes` → 完全不问，直接执行（供脚本使用，§9a）

> 实现备注：刻意**没有**用 `sys.stdin.isatty()` 提前跳过提问 —— 那样管道喂进来的答案
> （`echo q | ...`）会被无视，测试和脚本都没法驱动它。改成"永远问，读到 EOF 当放弃"，
> 既不会挂住，也绝不会在没得到明确确认的情况下动手。

## 4. 前置与失败（**大声失败**）

- [x] 输入文件不存在 → 报错文本里**含该路径**，退出码非 0（§4a）
- [x] 输入没有音轨 → 报错明确说「没有音轨」，**不是** ffmpeg 的一串日志（§4b）
- [x] 缺 ffmpeg → 报错含安装指引（单测 `test_no_ffmpeg_error_has_install_hint`）
- [x] 未装 ASR → 报错含 `pip install faster-whisper`（单测 `test_asr_missing_hint_mentions_pip`）
- [x] 四种错误文本**互不相同**（§4c + 单测 `test_four_error_texts_are_distinct`）

## 5. 找停顿

>    这与之前资产库 e2e 踩的"跨轮次脆弱"是同一类问题。
