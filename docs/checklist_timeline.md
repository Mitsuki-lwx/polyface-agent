## 1. 默认值表（**每一项都必须能被覆盖**）

| 项 | 默认值 | 覆盖方式 | 说明 |
|---|---|---|---|
| 时间线 `version` | `1` | 代码常量 | 不认识的高版本要**明确报错** |

## 4. 校验（**必须指出是哪一段**）

- [x] 空 `keep` → 拒绝，理由说"至少要保留一段"
      （实测 `TimelineError: 至少要保留一段（keep 不能为空）` ✓）
- [x] 两段重叠 → 拒绝，理由**指出是哪两段**（带段号与秒数）
      （实测 `第 2 段 [3.0, 8.0] 与上一段重叠（上一段止于 5.0）—— 保留区间必须升序且互不重叠` ✓）
- [x] `start >= end` → 拒绝，指出是哪一段
      （实测 `第 1 段 [5.0, 5.0] 的起不小于止` ✓）
- [x] 越界（超出源时长）→ 拒绝，指出越界的那一段**与实际时长**
      （实测 `第 1 段 [0.0, 34.84] 越界：源视频只有 24.840s` ✓）
- [x] 合法时间线 → 通过，且能落盘
      （实测 `validate()` 通过 ✓；落盘由 e2e 覆盖 —— `out.timeline.json` 已在媒体目录 ✓）
- [x] **校验只有一份实现**（Python 的纯函数）；`grep` 确认 Java 里没有第二套区间校验逻辑

## 5. 重渲染

- [ ] 从源视频重剪（**不是**从旧成片剪）—— 证据：日志里 ffmpeg 的输入是源文件
- [ ] 产出新成片，**不覆盖**源视频与旧成片
- [ ] 成片时长 == `keep` 推出的总长（容差内）
- [ ] 字幕用的是时间线里的 `segments`（改一条字幕 → 成片里真的变了）
- [ ] 重渲染是**任务**：能看到进度、能取消
- [ ] 重渲染任务**能断点续跑**（杀掉重启 → `interrupted`）

---

## 6. 字幕跟剪点走（**本模块最容易错的地方**）

- [ ] 删掉中间一段 → **落在该段内的字幕整条消失**
- [ ] 跨删除边界的字幕 → **被截断**（不是整条丢、也不是错位保留）
- [ ] 删完之后逐段抽查：**字幕与画面对得上**（时间轴换算到成片时间）
- [ ] 只改一段的结尾 → **别的段落的字幕不受影响**

## 7. 端到端（**必须真的改一次、真的重渲染**）

- [ ] 真实视频跑一次粗剪 → 得到时间线
- [ ] 打开时间线 → 看到每段的起止/时长/字幕/预览帧
- [ ] 删掉中间一段 → 保存 → 总时长变化**与预计一致**
- [ ] 重渲染 → 看到进度 → 完成
- [ ] 打开新成片：时长对、**被删内容确实没了**、**字幕不错位**
- [ ] 再改一次（只改一段的结尾）→ 再渲染 → 改一处不影响别处

## 未做（显式列出）

- **没做拖拽时间轴** —— 第一版是表格 + 预览帧（理由见 spec 关键决定二：先验证"改数据"好不好用）
- **没做导出剪映/FCPXML/EDL** —— 先做自己闭环，互通是下一期
- 没做分镜/镜头切分/音轨/转场/变速
- **没做撤销/版本历史** —— 改坏了可以从粗剪重来（时间线是派生数据，重跑粗剪就有新的）
- 时间线**不存 ffmpeg 参数**（渲染细节不进数据格式）
- 重渲染**从源重剪**的代价是**慢**（分钟级）—— 换来的是不叠加压缩损失、改字幕真的生效
- **字幕"是否错位"只做了程序化核对**（该消失的消失、其余恰好一次、时间轴换算对）
  —— **没有人工看片逐段确认**画面与字幕的对应
- 端到端用的是 `make_fixture.py` 造的 24.84s 素材（Windows TTS），不是真人录制
- 预览帧用的是 `<video>` seek（每行一个视频元素）—— 行数多时（比如几十段）会偏重，
  本版没做虚拟滚动/懒加载
- `segments_to_source` 在**边界**上的取整用的是"起点贴左、终点贴右"；
  更精细的语义（比如按语音活动对齐）没做

## 顺带修掉的（实测才发现的，都不是本模块新写的）

| 问题 | 现象 | 根因 |
|---|---|---|
| 字幕**重复 + 28ms 碎片** | 同一句出现两次，其中一段只有 28 毫秒 | `segments_to_film` 按保留区间**拆**字幕 —— 但成片是**连续的**，源区间映射过去本来就该是一个条目 |
| `/api/timelines` 列出 **srt** | 时间线列表里混进 `render.srt`，`GET` 它还把字幕文本当 JSON 解 | `timeline` 在资产模型里是**类**（json/srt/vtt/ass 都归它），只判 kind 不够 |
| **预览帧全空** | `<video>` `readyState=0`，不出画面 | 媒体托管路径是 `/api/media/**`，代码里拼了 `/media/` → 404 |

第三条正是**浏览器实测**才揪出来的 —— 接口返回 200、时长也对，光看接口发现不了。
