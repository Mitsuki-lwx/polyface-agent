# checklist —— 运行透明化：阶段事件 + 进度可见 + 参数可问

对 `docs/spec_observability.md` 的可勾选验收。**一行一条，可独立判定。**

> 状态：**未开工**（本文件先于实现写，验收时逐条勾）

---

## 1. 默认值表（**每一项都必须能被覆盖**）

| 参数 | 默认值 | 依据 |
|---|---|---|
| 输出级别 | **正常**（阶段 + 耗时 + 进度 + 重要行 + 心跳） | 安静看不到过程，详细会刷屏 |
| 心跳间隔 | **5s** | 长阶段不至于看起来卡死；再密就是刷屏 |
| 事件文件 | **开**，落 `{数据目录}/runs/<run_id>.jsonl` | 沿用既有本地 JSONL 姿态 |
| 事件 schema 版本 | **1** | 格式给机器读，必须带版本 |
| 默认问哪些参数 | **只问停顿阈值**（其余展示当前值，可改但不主动问） | 它是唯一会显著改变结果的旋钮 |
| 非交互开关 | **`--yes`**（不问，直接用生效值） | 沿用既有开关名，不另造 |

## 2. 阶段事件：格式与落盘

- [ ] 事件是**一行一个 JSON**，可被逐行解析（不依赖整体读取）
- [ ] 每条带：运行标识 / 阶段名 / 事件类型 / 时间 / 耗时 / 一句人话 / 机器可读字段 / schema 版本
- [ ] 事件类型至少覆盖：开始、进度、结束、失败
- [ ] 事件文件里**搜不到素材内容**（台词原文、字幕文本都不该出现）
- [ ] 关掉事件文件 → **不创建任何文件**
- [ ] 事件文件路径可配；默认在数据目录下的 `runs/`

## 3. 观测不影响业务（**硬不变量**）

- [ ] 把事件文件目录设成**不可写** → 粗剪**仍然跑完**，退出码 0
- [ ] 上报失败时终端**有告警**（不静默吞掉）
- [ ] 关掉全部输出 → 业务结果与默认档**完全一致**（时长、剪点数）
- [ ] 事件上报**不改变**任何业务决策（剪点、参数、产物）

## 4. 输出分级

- [ ] 安静档：终端**没有阶段行**，只有最终结果与错误
- [ ] 正常档（默认）：能看到**每个阶段一行**（名字 + 耗时）
- [ ] 详细档：能看到底层工具的原样输出
- [ ] 一个"故意很慢"的阶段（≥12s），正常档下**至少出现 2 次心跳**
- [ ] 三档的输出行数**严格递增**（安静 < 正常 < 详细）

## 5. 进度

- [ ] 转写阶段能看到**百分比变化**（不是只有开始/结束两行）
- [ ] 渲染阶段能看到**百分比变化**
- [ ] 进度百分比**单调不减**，且**不超过 100%**
- [ ] 进度上报**不影响**最终产物（与关闭进度时的成片一致）

## 6. 运行报告

- [ ] 报告含：每步耗时 / 本次生效参数 / 剪点 / 产物位置
- [ ] 报告里的**每个路径都真实存在**（成片、字幕、剪点文件、中间件目录）
- [ ] 报告里的耗时与事件文件里的对应阶段**一致**（误差 ≤ 0.5s）
- [ ] 失败时报告**说明失败在哪一步**，而不是只丢一句"失败"

## 7. 参数可问

- [ ] 开始前能看到**本次生效的全部参数**（不只是被问的那几项）
- [ ] 每项参数能看出**来源**（默认 / 配置文件 / 命令行）
- [ ] 默认只问**停顿阈值**（不刷屏）；可配成问全部 / 什么都不问
- [ ] 当场改的值**真的生效**（跑完报告里体现）
- [ ] 非交互开关 `--yes` 存在且行为正确（完全不问）
- [ ] 管道喂答案（`echo q | ...`）仍然可用（不被 `isatty` 吃掉）

## 8. 端到端（**至少一条**）

- [ ] 一条命令跑完 → 终端有阶段与报告，事件文件存在且可解析
- [ ] 同一素材跑**安静档**与**正常档** → 产物**完全一致**，终端输出**明显不同**
- [ ] 事件目录不可写时跑一次 → **业务仍成功**
- [ ] 全程**不出网**

## 9. 变异测试（至少 1 次）

- [ ] 故意让某个阶段**不发结束事件** → 确认 e2e **变红** → 还原 → 复绿
- [ ] 故意让**心跳停止** → 确认"慢阶段有心跳"那条**变红** → 还原 → 复绿
- [ ] 记录变异前后的实际数字

## 10. 诚实边界（验收时必须如实填）

- [ ] 工作台进度条 UI **未做**（spec 的 Out of Scope）；只验了终端与事件文件
- [ ] 多任务并发 / 异步 / 断点续跑 **未做**（M8）
- [ ] 既有 LLM 观测（trace/用量）**未改造**成同一底座
