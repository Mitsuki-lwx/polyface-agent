## 本轮修掉的四个真问题（都是实测撞出来的）

1. **退出码 0 ≠ 有产出**：拿已剪过的视频再剪 → CLI 正常退出但不产文件 → 任务被记成"✅ 完成"却没有产物。
   已加"没产出也算失败"。
2. **子进程 stdout 是 GBK**：CLI 打 `✓` 直接 `UnicodeEncodeError`，而且崩在**产物写完之后**，白干一场。
   已让 CLI 在被重定向时写 UTF-8。
3. **读子进程日志用严格 UTF-8 会抛**：`MalformedInputException` 被误报成"启动失败"，
   把一次**成功的**任务记成了失败。已改宽松解码，并把"读日志"从"启动"里拆出来。
4. **`.srt` 不在资产白名单里**：登记字幕时抛错，把后面的**剪点登记与源视频关联**一起带崩。
   已把 srt/vtt/ass 归入 `timeline`。
