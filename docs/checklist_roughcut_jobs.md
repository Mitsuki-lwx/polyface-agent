# checklist —— 粗剪任务化：异步任务 + 工作台入口

对 `docs/spec_roughcut_jobs.md` 的可勾选验收。**一行一条，可独立判定。**

> 状态：**未开工**（本文件先于实现写，验收时逐条勾）

---

## 1. 默认值表（**每一项都必须能被覆盖**）

| 参数 | 默认值 | 依据 |
|---|---|---|
| 轮询间隔 | **1s** | 阶段粒度足够；再密是白打接口 |
| 并发任务数 | **1**（串行） | 单机单用户；视频转码本来就吃满 CPU |
| 任务保留 | **最近 50 条** | 列表够看，不无限涨 |
| 卡死判定 | **300s 无新事件** | 比最长单阶段（5 分钟素材的转写约 60s）留足余量 |
| 参数默认值 | **与 CLI 完全一致** | 复用 `RoughcutParams`，不另造一套 |
| Python 可执行 | `<包根>/python-service/.venv/Scripts/python.exe` | 与启动脚本一致；可配 |
| 粗剪脚本 | `<包根>/scripts/roughcut.py` | 同上 |

全部可从配置或命令行到达；**CLI 单独用仍然可用**（工作台不是唯一入口）。

## 2. 任务模型

- [ ] `job` 表落盘，含：状态 / 类型 / 参数 / 输入 / 产物 / 事件文件路径 / 创建·开始·结束时间 / 错误
- [ ] 状态机只有这几个：`排队 / 运行 / 成功 / 失败 / 已取消`（没有别的隐含态）
- [ ] **重启服务后任务列表还在**，且能看到上次是成了还是败了
- [ ] 任务超过保留条数时**裁掉最老的**（不是无限涨）

## 3. 执行

- [ ] 发起后**真的起了子进程**（不是同步跑在请求线程里）
- [ ] 子进程退出码被**正确解读**（0=成功、非 0=失败，且错误可读）
- [ ] **进程意外死亡**能被识别：不会一直显示"运行中"
- [ ] 输入文件不存在 → 任务快速失败并给出**含路径**的原因
- [ ] 未装 ffmpeg / ASR → 失败信息里有**可执行的指引**（不是一串底层日志）
- [ ] 产物路径含空格/中文时仍然正确

## 4. 进度

- [ ] 任务详情能报出**当前阶段名**
- [ ] 能报出**百分比**（来自事件文件，不是猜的）
- [ ] 能报出**已完成的阶段列表**
- [ ] 事件文件**缺失**时不崩，只是进度未知
- [ ] 事件文件**写到一半**（半行 JSON）时不崩
- [ ] 长时间无新事件 → 标记为**疑似卡死**（不是永远"运行中"）

## 5. 取消

- [ ] 取消后**进程真的没了**（查进程/端口，不是只改了状态）
- [ ] 取消**幂等**：重复取消不报错
- [ ] 取消已结束的任务 → 200 且状态不变
- [ ] 取消后**不留下孤儿进程**（Windows 上要杀进程树）

## 6. 产物与素材库

- [ ] 成功后成片 / 字幕 / 剪点**自动出现在素材库**
- [ ] 产物**关联到源视频**（能看出"这条成片是从哪个视频剪的"）
- [ ] **登记失败不影响任务成功**（注入不可写目录验证）
- [ ] 任务失败时**不产出**半成品资产

## 7. 前端

- [ ] 素材库的**视频资产行**有「粗剪」入口；**非视频资产没有**（图片/音频不该出现）
- [ ] 参数弹层显示**本次生效的默认值**（与 CLI 一致）
- [ ] 改参数后发起的任务，详情里**确实是改后的值**
- [ ] 进度**可见**：当前阶段 + 百分比 + 最后一次心跳时间
- [ ] 任务结束后**轮询停止**（不再打接口）
- [ ] 任务列表可查最近若干条，含状态与产物入口
- [ ] 缺 ffmpeg / ASR 时给**可执行指引**，不是报错
- [ ] **不使用 `alert()`**（headless 下会阻塞页面）

## 8. 端到端（**至少一条**）

- [ ] 浏览器实测：素材库发起 → 看到进度推进 → 完成 → 产物出现在素材库（**含截图**）
- [ ] 取消一次真跑中的任务 → 进程真的消失
- [ ] **重启服务** → 任务列表与状态还在
- [ ] **CLI 单独跑仍然可用**（不经工作台）
- [ ] 全程**不出网**

## 9. 变异测试（至少 1 次）

- [ ] 故意**不处理子进程退出码**（永远记成功）→ 确认 e2e **变红** → 还原 → 复绿
- [ ] 故意**不杀进程树** → 确认"取消后进程没了"那条**变红** → 还原 → 复绿
- [ ] 记录变异前后的实际数字
