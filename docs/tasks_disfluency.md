# tasks —— 口播去冗余（去口误 / 重复句 / 口头语 / 半句废弃）

对应 spec：`docs/spec_disfluency.md`　　验收：`docs/checklist_disfluency.md`

顺序按**依赖**排：判定能力 → 合并 → 接入 → 端到端。
每个任务一次专注会话能做完。

## T1　词级时间戳转写入口

- **影响文件**：`python-service/app/pipeline/asr.py`、`python-service/tests/test_asr_words.py`（新）
- **依赖**：无
- **做什么**：给本地 ASR 适配层加一个"要**词级**时间戳"的入口（现有的是段级）。
  输出：`[{start, end, text, words:[{w, start, end}]}]`
- **参考**：`asr.py` 现有段级实现（106 行，照它的样子写）
- **验收**：单测喂一段合成音，返回的 words 非空、时间戳单调递增、覆盖区间与段级一致

---

## T2　规则判定：口头语 + 完全重复 + 半句重起

- **影响文件**：`python-service/app/pipeline/disfluency.py`（新）、`python-service/tests/test_disfluency_rules.py`（新）
- **依赖**：T1
- **做什么**：三类**高置信**规则判定：
  1. **口头语**：命中词表（外露可改）且**独立成词**（"那个"在"那个人"里不算）
  2. **完全重复**：相邻两句归一化后**完全相同**（去标点/空白）
  3. **半句重起**：相邻两句的**前缀**高度相似但后者更长（「我们今天要讲的」→「我们今天要讲的是」）
- **每条产出**：`{start, end, kind, evidence, source:"rule"}`
- **参考**：`roughcut.py:207 detect_pauses` 的返回形状（区间列表）
- **验收**：每条规则各有 1 条"该抓"和 1 条"不该抓"的用例（口头语要验"那个人"不误伤）

---

## T3　相似度判定：换措辞的重说

- **影响文件**：`disfluency.py`、`tests/test_disfluency_rules.py`
- **依赖**：T2
- **做什么**：相邻句对算相似度（字符级 + 词级取高），超过阈值 → 标为"疑似重复"，
  `source:"rule"`、`confidence:"low"`（**低置信**，留给 T4 复核）
- **可调**：阈值（外露参数）
- **验收**：构造"同一件事换个说法"的句对 → 被标 low；"两件不同的事"→ 不标

---

## T4　模型复核（只判可疑段）

- **影响文件**：`disfluency.py`、`python-service/app/pipeline/prompts.py`、`tests/test_disfluency_llm.py`（新）
- **依赖**：T3
- **做什么**：把**低置信的可疑句对**（只有这些，不是全文）交给 LLM，问"这两句是不是在说同一件事"。
  返回 `{start, end, kind, evidence, source:"llm"}`
- **关键**：模型**只回答判断**，不返回时间戳 —— 时间戳由程序从原句对取
- **降级**：模型不可用/超时 → 返回空并**明确标记** `llm_skipped`（不静默）
- **参考**：`llm.py` 的 `chat_json`（现有生成链路在用）
- **验收**：mock 模型返回"是"→ 标为重复且 `source:"llm"`；返回"否"→ 不标；抛异常 → `llm_skipped=true` 且不崩

## T5　合并剪点（冗余 + 停顿）

- **影响文件**：`disfluency.py`、`roughcut.py`（新增合并函数）、`tests/test_merge_cuts.py`（新）
- **依赖**：T2、T4
- **做什么**：把冗余区间与停顿区间**合并成一份**：
  - 重叠/相邻的区间并起来
  - 太短的片段（低于最短时长）丢弃 —— 剪掉 0.1 秒没有意义还伤音频
  - 边界**向两侧回退**到语音边界 + 余量（spec 关键决定四）
- **参考**：`roughcut.py:217 plan_cuts`（它已经在做"停顿→剪点"的转换，照它的形状）
- **验收**：重叠区间合并后不重复；相邻的接上；低于最短的丢弃；回退后不侵入语音

## T6　参数外露（三层优先级）

- **影响文件**：`roughcut.py` 的 `RoughcutParams`、`config.py`
- **依赖**：T2、T3、T5
- **做什么**：新增参数（**每一类一个开关** + 相似度阈值 + 口头语词表 + 最短片段时长），
  走现有三层优先级：`内置默认 < 配置文件 < 命令行`
- **参考**：`roughcut.py:48 RoughcutParams`（现有的参数定义与解析）
- **验收**：改配置文件的词表 → 判定结果确实变；命令行覆盖配置 → 生效；不填 → 用默认

## T7　判定结果落盘 + 可解释报告

- **影响文件**：`disfluency.py`、`roughcut.py`（报告）
- **依赖**：T5
- **做什么**：
  - 判定结果落盘（区间、类别、依据、来源）—— 调参不必重新转写
  - 报告里逐条列出"剪了哪几段、为什么、来源是规则还是模型"

- **验收**：报告里每条判定都能看到依据；重复跑一次用同样的落盘结果（不重新转写）

## T8　接入主流程（两段式）

- **影响文件**：`python-service/app/main.py`（端点）、`java-backend/.../job/RoughcutRunner.java`（或新增 runner）、`java-backend/.../web/JobController.java`、`static/index.html`
- **依赖**：T5、T6、T7
- **做什么**：

- **验收**：发起 → 看到含理由的方案 → 确认 → 成片；关掉某一类 → 该类不再出现在方案里
