## 2. 交付内容

### 2.1 数据层（Store）

- 新增表 `template`：`kind / name / voice / opening / structure_json / closing / tag_style / taboo_json / builtin / origin_id / version / created_at / updated_at`
- `draft` 表新增 `template_id`、`template_version`（**幂等迁移**：查 `PRAGMA table_info` 后按需 `ALTER TABLE`）
- 新增方法：`insertTemplate / getTemplate / listTemplates / findTemplateByName / updateTemplate / overwriteTemplateByName / deleteTemplate / countBuiltinTemplates`
- `insertDraft` 新增重载（带模板版本），旧签名保留 → 向后兼容

### 2.2 接口（TemplateController + TemplateMapper）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/templates?kind=` | 列表（内置在前，我的在后） |
| POST | `/api/templates` | 新建 → 201 |
| GET | `/api/templates/{id}` | 详情 |
| PUT | `/api/templates/{id}` | 编辑（version +1） |
| DELETE | `/api/templates/{id}` | 删除（内置 → 409） |
| POST | `/api/templates/{id}/duplicate` | 复制为我的（记 `origin_id`） |
| GET | `/api/templates/export` | 导出（去本机标识，带 `polyface_templates` 版本字段） |
| POST | `/api/templates/import` | 导入（**同名冲突未指定策略 → 409 + conflicts 清单**） |

导入策略（由用户裁决）：`skip` 跳过 / `overwrite` 覆盖 / `keep_both` 保留两者（名称加 `(导入)` 后缀）。
内置模板不可被覆盖 → `overwrite` 命中内置时**降级为并存**，不破坏只读红线。

### 2.3 预置模板库

`java-backend/src/main/resources/presets/content-templates.json` — 3 个：结论前置·清单体 / 故事共鸣体 / 干货教程体。
`TemplateSeeder` 启动时**仅当 builtin 为空才 seed**，此后不覆盖用户任何改动。

### 2.4 生成接入（FR-64）

- `GenerateRequest` 新增 `template_id`；**优先级 `template_id` > 内联 `template`**（内联保留为兼容快捷方式）
- Java 查库 → `TemplateMapper.toUserTemplate` → 透传 Python（Python 侧契约不变，保持无状态）
- 落库时把 `template_id` / `template_version` 写入 draft；生成响应与查询接口均返回该信息

### 2.5 前端（static/index.html，零构建）

- 新增「⑤ 模板库」卡片：内置/我的分组、新建/编辑/复制/删除/导出/导入
- 生成页新增模板下拉选择器（`optgroup` 分组，显示 `名称 v版本`）；原内联表单折叠为「临时模板（不保存）」
- 稿件卡显示 `🧩 模板：{名称} v{版本}`；模板删除后显示「模板已删除（#id v版本）」
- 导入冲突 → 弹窗列出冲突项 + 三选项（跳过/覆盖/都保留），选择后带策略重提

## 4. 关键实现说明

- **幂等迁移**：SQLite `ALTER TABLE ADD COLUMN` 非幂等，改用 `PRAGMA table_info(draft)` 检测缺列再执行，老库可原地升级（`schemaMigrationIsIdempotent` 测试覆盖）。
- **冲突交用户判断**：后端不在冲突时自行决策，返回 409 + 冲突清单（含 `existing_id` / `existing_builtin`），前端弹窗三选项后带 `on_conflict` 重提。
- **内置只读红线**：`DELETE` 内置 → 409；`overwrite` 命中内置 → 降级为并存，内置内容永不被改写。
- **模板优先级**：用户模板 > 平台 DNA 结构/风格；平台 `limits`/红线仍由 QA 强制（ADR-014，未变）。
- **向后兼容**：旧内联 `template` 字段、旧 `insertDraft` 签名、`clip` kind 预留在位，无一破坏。
