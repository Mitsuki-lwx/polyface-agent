# checklist —— B1 图文成片

上游：`docs/spec_b1.md`　　tasks：`docs/tasks_b1.md`

> 每一项都必须**可勾选、可观测**。**至少一条端到端验收**（§9），且必须**真的出片并打开核对**。
> 验收完如实填 §10 与「未做」。

---

## 1. 默认值表（**每一项都必须能被覆盖**）

| 项 | 默认值 | 覆盖方式 | 说明 |
|---|---|---|---|
| 对齐策略 | `voice_first`（配音优先） | 命令行 / 接口 / UI | spec 关键决定二 |
| 转场时长 | 0.4s | 命令行 / 接口 / UI | 太长会显得拖沓 |
| 缓动强度 | 1.08（放大到 108%） | 命令行 / 接口 / UI | 1.0 = 静止（那就退化成轮播了） |
| BGM 音量 | -18 dB（相对配音） | 命令行 / 接口 / UI | 配音必须听得清 |
| BGM 淡出 | 1.5s | 命令行 / 接口 / UI | |
| 节拍容差 | 0.12s | 命令行 / 接口 | 判定"落在节拍上"的窗口 |
| 字幕字号/颜色/边距 | 沿用 `RoughcutParams` 同名字段 | 命令行 / 接口 / UI | 与粗剪一致，别立第二套 |
| 配音缺失时 | 降级为无声 + 字幕 | 不可配（行为） | **绝不因缺依赖而整体失败** |
| librosa 缺失时 | 跳过卡点并**说明未做** | 不可配（行为） | |

**验收**：每行在 §2 里有对应观测（不可配的项 → 变异测试）。

---

## 2. 参数与常量（改了行为要变）

- [ ] 缓动强度改成 `1.0` → 画面**静止**（抽首尾帧应当相同）
- [ ] 转场时长 0.4 → 1.2 → 成片总时长相应变化（可量）
- [ ] BGM 音量改成 `0` → 成片里**听不到 BGM**（可量：音频轨的能量差）
- [ ] 节拍容差改成 `0.001` → 记录里"落在容差内的边界占比"**明显下降**（说明它是算出来的）

---

## 3. 可选依赖降级（**本模块最容易做错的地方**）

- [ ] **卸掉/屏蔽 TTS** → 出成片（无声 + 字幕），**不报错**，输出里有安装指引
- [ ] 装回 TTS → 成片有配音
- [ ] **屏蔽 librosa** → 出成片，输出里**明确说明"未做卡点"**，记录里对齐占比标为"未检测"
- [ ] 装回 librosa → 有节拍、有对齐占比
- [ ] 缺 TTS 与缺 librosa **同时发生** → 仍然出片（无声 + 无卡点 + 字幕）

---

## 4. 配音与时长（spec 关键决定一）

- [ ] 每个分镜的时长 == 该分镜配音的**实际时长**（不是 `duration_hint`）
- [ ] `duration_hint` 与配音长度**明显不符**时，以**配音**为准（构造一个刻意不符的分镜验证）
- [ ] 分镜顺序 == 剪辑单顺序（不重排）

---

## 5. 画面与转场

- [ ] 每个分镜的画面是**用户选的那张图**（不是随机图、不是占位图）
- [ ] 画面**在动**：抽同一分镜的首帧与尾帧，**必须不同**
- [ ] 分镜之间**不是硬切**：抽转场中间帧，能看到两图混合
- [ ] 缺图的分镜 → **明确指出是第几个**，不静默用占位图

---

## 6. BGM 与卡点（两种策略必须真的不同）

- [ ] `voice_first`：**分镜时长与 §4 完全一致**（配音没被改）
- [ ] `voice_first`：记录里有 BGM 偏移量，且偏移是**为了让更多边界落在节拍上**算出来的
- [ ] `beat_first`：分镜边界**落在节拍容差内**的占比**明显高于** `voice_first`
- [ ] `beat_first`：允许分镜时长与配音长度**不一致**（记录里要能看出来）
- [ ] 记录里的"落在节拍容差内的边界占比"是**算出来的真值**（改容差它会变，见 §2）
- [ ] BGM 结尾有淡出

---

## 7. 初剪记录（`*.plan.json`）

- [ ] 字段齐全：每个分镜的时长/用的图/字幕、节拍点、BGM 偏移、对齐策略、对齐占比
- [ ] 记录里的时长与**成片实际时长**一致（容差内）
- [ ] 记录里能看出"这次怎么剪的" —— 人工定稿时够用（自己读一遍，判断）

---

## 8. 任务化

- [ ] 成片走任务：能看到进度、能取消
- [ ] **分镜级落盘**：跑到第 3 个分镜时，`done/` 里有 3 个
- [ ] 杀掉服务重启 → `interrupted` → 继续 → **只补没做完的分镜**（不重跑全部）
- [ ] 产物进素材库，血缘挂到源素材/成稿

---

## 9. 端到端（**必须真的出片并打开核对**）

- [ ] 真实素材 → 成稿（含剪辑单）→ 3~4 张自己的图 + 一首 BGM → 成片
- [ ] 打开成片：时长对、每个分镜是选的图且在动、字幕对应不错位、BGM 有声且淡出
- [ ] 切 `beat_first` 再跑 → 对齐占比**明显提高**（两次记录可对比）
- [ ] 卸掉 TTS 再跑 → 无声成片 + 安装指引，不报错
- [ ] 上面每一步的**原始输出都留着**

---

## 10. 诚实边界（验收时必须如实填）

- [ ] 明确记录：**不内置图片与 BGM**（版权/体积/"模板感"三重理由，见 spec 关键决定四）
- [ ] 明确记录：**不接图像生成**（会引入新服务商）
- [ ] 明确记录：产物是**初剪**，不做"零人工出网感"的承诺（`docs/49` §5.2）
- [ ] 明确记录：TTS 与 librosa 都是**可选依赖**，不进发布包 → **发布包不显著变大**
- [ ] 明确记录：**数据边界不变** —— TTS 与节拍检测全本地，**ADR-017 与 README 都不需要改**
- [ ] 明确记录：`beat_first` 会**改变脚本时长**（配音伸缩/留白、字幕跟着变）—— 这是它的代价
- [ ] 明确记录：卡点精度受节拍检测质量限制，**不保证每个边界都精确踩点**
- [ ] 明确记录：BGM 的**版权由用户负责**（本工具只用他给的本地文件）
- [ ] 明确记录：`docs/49` §5.1 的约束**只能缓解不能消除** —— 缓动 + 克制张数 + 转场
      让观感远离"模板感轮播"，但形态本身仍是图片类内容

## 11. 变异测试（**必须做，绿不等于有效**）

- [ ] 把缺 TTS 的降级改成"抛异常" → §3 的断言**变红** → 还原

- [ ] 把对齐占比改成写死的常量 → §6 的"改容差它会变"**变红** → 还原
