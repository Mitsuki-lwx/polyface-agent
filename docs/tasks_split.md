# tasks —— 素材拆分（一个素材 → 多个素材源）

上游规格：`docs/spec_split.md`　　验收：`docs/checklist_split.md`

> 8 个任务。**最后两个（接入主流程 / 端到端验证）是硬要求。**

---

## T1 · 数据契约与存储

**影响**：`store/Store.java`（material 加 `parent_id` / `angle`）· `docs/spec_split.md`

给 `material` 加两列：`parent_id`（从哪个父素材拆的）、`angle`（这一条的角度）。
老库自动补列（仓库已有 `ensureXxxColumn` 的先例）。

**验收**：老库平滑升级；普通素材的 `parent_id` 为空。

---

## T2 · Python：拆分调用

**影响**：`app/pipeline/split.py`（新建）· `schemas_gen.py`

一次 LLM 调用：输入 = 父素材全文 + 父素材事实清单 + 角度列表；
输出 = 每条的 `{angle, title, core_message, facts[]}`。

**要点**：`facts` 必须是**父素材事实的子集**，且能指出**来自父素材的第几条**
（与 `docs/spec_factguard.md` 的"事实依据声明"同一条思路）。

**验收**：3 个角度 → 3 条。

---

## T2b · Python：**按形态**拆（channels and **formats**）

**影响**：`app/pipeline/split.py` · `schemas_gen.py`

**依赖**：T2

**做什么**：黑客松原句写的是 "different channels **and formats**" ——
形态是**明写着的**，不能只做选题。同一份内容 → 长文版 / 口播脚本 / 图文 / 金句卡片。

**要点**：选题与形态是**两个维度**，输入要能表达两维：

```
只给选题            → 按选题拆（每条一个角度）
只给形态            → 同一内容出多种形态
两个都给            → 选题 × 形态 的矩阵（注意别爆量）
```

**验收**：给 3 个形态 → 出 3 条，各自真的是那个形态（口播版有口语与停顿提示、
金句卡片只有一句话）；事实仍然只能来自父素材（同一套序号机制）。

---

## T3 · Python：拆分结果校验

**影响**：`split.py`

- 角度数 == 产出条数（少了要**说清是哪个角度**）
- 每条 facts 都能在父素材事实里找到（**一条都不能多**）

**验收**：构造"模型多编一条事实" → 被拦下并指出是哪条。

---

## T4 · Java：端点 + 任务化

**影响**：`web/`（新端点）· `job/`（复用任务化）

`POST /api/materials/{id}/split`，body = `{angles: [...]}`。
走**任务**（分钟级）—— 复用 `docs/spec_resume.md` 那套：进度、取消、断点续跑。

**验收**：发起 → 看进度；杀掉重启 → `interrupted` → 能继续。

---

## T5 · Java：落成子素材 + 血缘

**影响**：`web/` · `store/`

拆出来的每条**落成一个真正的素材**（进同一个 `material` 表），带 `parent_id` / `angle`。
父素材能反查"我拆出了哪些"。

**验收**：拆 3 条 → 素材库里多 3 条，各自能打开、能再走一遍生成。

---

## T6 · 拆分记录

**影响**：`job/`（产物落盘）

留一份 `split.json`：拆了几条、每条的标题/角度、**用了父素材的哪几条事实**。

**验收**：能按记录逐条复核"这条是从哪几条事实来的"。

---

## T7 · 接入主流程（**必须有**）

**影响**：`index.html`

素材详情页给一个「拆分」入口：填条数与角度 → 发起 → 看进度 → 列出拆出的子素材
（点进去就是普通素材，能直接生成稿件）。

**验收**：浏览器实测（真拆一次、真点进子素材）。

---

## T8 · 端到端验证（**必须有**）

**影响**：无（验证任务）

1. 拿一份真实长素材（比如 `dl.mp4` 的字幕文案）→ 拆成 3 条
2. 逐条核对：**事实有没有超出父素材**（逐条对着父素材事实清单看）
3. 拿其中一条子素材 → 生成多平台稿件 → 确认能走通完整管线
4. 再看父素材：能查到"我拆出了哪 3 条"
5. 故意给一个"父素材里没有的角度" → 看它怎么处理（应如实说拆不出来，不是硬编）

**验收**：上面 5 步的原始输出都留着；**哪一步没做到就如实写没做到**。
