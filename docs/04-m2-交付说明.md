## 新增能力

- **brief（平台策略）**：angle / hooks / structure_plan / tag_direction / rationale
- **draft（成稿）**：titles[3] / body / tags / cover_suggestion / interaction_line / rationale
- **qa（质量门）**：规则校验（正文字数上限、标签数量上限、标签格式、标题缺失）+ mock/LLM 自评；真实模式下未过 QA 带反馈重写一轮
- **防幻觉**：understand 产出事实清单 → draft 提示词限定只能用事实清单信息 → QA 再次校验正文数字是否有素材依据（无依据 → warning）
- **本地存储**：`data/polyface.db`（SQLite，gitignore），素材 + 稿件双表
