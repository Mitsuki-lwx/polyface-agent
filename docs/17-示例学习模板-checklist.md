**E 层（浏览器实测，2026-09-10）**：headless Edge + CDP 驱动真实浏览器，逐条操作并读取真实 DOM：

| 项 | 实测结果 |
|---|---|
| E1 学习入口 | 「✨ 从示例学习」按钮在位 |
| E2 学习弹窗 | 弹窗打开，示例文本框 + 来源备注框均在位 |
| E3 合规提示 | 含「不会保存示例原文」「请只使用自有或已获授权的示例」 |
| E4 提交后刷新 | 弹窗自动关闭，列表 3→4（草稿 0→1） |
| E5 草稿展示 | 显示「草稿 · 待确认」徽章、来源、`AI 拆解结果，请核对后启用` |

### 关键验收点（UC-16）

- ✅ 拆解产物一律 `status=draft`，**未确认不出现在生成页选择器**（服务端默认只返回 active + 前端过滤，双重保障）
- ✅ 草稿可预览结构、可编辑（编辑后仍为 draft）、确认后才启用
- ✅ 不保存示例原文（仅拆解结果 + 来源备注）
