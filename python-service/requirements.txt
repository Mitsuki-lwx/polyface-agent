# faster-whisper：粗剪/入料的本地语音转写。装了会拖进 torch（数百 MB），
# 违背"本地一键启动"的卖点，所以不进默认安装；需要时自己
#   pip install faster-whisper "av<17"
# ⚠️ **`av` 必须 <17**（实测 2026-10-14）：PyAV 19.0.1 **去掉了** `av.open(..., metadata_errors=)`
#    这个参数，而 faster-whisper 的 `audio.py` 一直在用它 →
#       open() got an unexpected keyword argument 'metadata_errors'
#    16.0.1 有这个参数（已验证），钉住它之后转写正常（实测 4 段、中文正确）。
#    （先怀疑过 huggingface-hub，**是误判** —— 降它没有任何影响，别重走这条路。）
#    另：模型要能**本地加载**（默认 small）。缓存里没有就会去 HuggingFace 下，
#    连不上时报 LocalEntryNotFoundError。模型缓存在 ~/.cache/huggingface/hub/。
# 不装的表现见 README FAQ「粗剪需要装什么」—— 明确报错并给指引，不会静默降级。

#    而按场景切段是 B2 的核心能力之一 —— 发布包里缺它，等于该功能对用户直接不可用。
